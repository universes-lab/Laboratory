# Laboratory (Workspace) проекта HONC

Это пространство для исследований, экспериментов и первичной обработки знаний.

## Структура
- `Temporal/` — зона для текущих разработок проекта HONC: исходные тексты, черновики, эксперименты.
- `NFSI-01/` — архив предыдущих наработок и экспериментов ВПК/ТД.
- `AI-Sociology/` — "проект коллективного разума ИИ"
- `Knowledge-DNA/` — медодика анализа паттернов знаний 
## Принцип работы
Лаборатория является буфером перед переносом утвержденных объектов в каноническую библиотеку HONC.
