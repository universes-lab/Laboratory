## 2. Протокол работы — соблюдать с первого хода
SCIENTIFIC ZOV LOCK:
  FRAME: <OBJECT_LEVEL> | <OBSERVER> | <frame|field|bridge>
  QUESTION: <один вопрос>
  1. Сначала ответ на QUESTION — первым абзацем.
  2. Оставаться внутри FRAME.
  3. Смена FRAME — только явным FRAME SHIFT.
  4. FRAME SHIFT не переносит действительность вывода автоматически.
  5. Каждый зарегистрированный результат хранит свой исходный FRAME. Ссылка на результат из другого
     FRAME — это FRAME SHIFT. Для отношений в объект входит сторона: источник / поле / пробник.
  6. ANSWER → STOP. Никаких непрошеных следующих веток.
- FRAME нижнего уровня несёт два дискретных счёта dt/dx: по пространственным квантам и по кадрам
  наблюдения (кино с вложенными микрофильмами, образ числа π). И несёт модель-образ уровня.
- Метки парадигмы: [dt/dx] / [мост] / [метафора]. В [dt/dx] нет слов «сила», «энергия», «импульс»,
  «притяжение», «толчок», «передача».
- Статусы: [К] канон · [Д] вывод · [Г] гипотеза · [О] открыто · [С] снято. Один набор, без [G] и смеси.

## 3. Терминология
- Квант (λ) — ячейка. Квантинуум — микроконтинуум внутри кванта; сам состоит из квантов.
  Квантрон — паттерн масштаба ≫ λ. Пустоты нет нигде: везде кванты своего Q-типа.
- Обозначения: Q0 = 3D · Q1 = (2D+1D) — общий центр · Q2 = (2D−1D) — центры смещены ·
  Q3 = 3×1D — три несвязанных.
- Слои (R-4): Q-уровень = топология систем отсчёта; λ-молекулы и выше = структуры поля времени.
  Поле — следствие, система отсчёта первична.
- Оси (R-2): основная (экваториальная проекция) · дополнительная (меридиональная) ·
  виртуальная Z (только направление; при ⊥ осей 1D и 2D) · супер-Z (⊥ и смещение центров, Q2).
  ∥/⊥ у Q1 — оси вращения, а не положение кольца: кольцо всегда на экваторе своего 2D.
- Движется не вещество и не квант, а состояние системы отсчёта кванта.
- c — граница (минимальная медленность), не обязанность. К ней подходят только открытые f и ν.

## 4. Что установлено (главное)
Топология систем отсчёта:
- R-1: Q3 — система отсчёта без применения; нет выбора XYZ/YXZ; абсолютная нейтральность. [К]
  Q3 — нулевая отметка вращательной доли, не прибор.
- R-2 → Q1 может покоиться (виртуальная Z), Q2 обязан лететь (супер-Z). [Д]
- Латчерная связь — топологическое отношение (зацепление), не компонента и не структура.
  L молекулы — сумма по всем прохождениям кольца сквозь тор. [Д]
- L = 0 у всех Q1 (центры неразрывны, кольцо не продето); L = ±1 у Q2. Кандидат «L ↔ заряд»
  на уровне кванта для кварков не работает.
- Третья компонента: у Q1 стоячая (только при ⊥ осей вращения), у Q2 бегущая. [Д] из R-2.
  Единое электромагнитное поле — классический предел. [Г]+[мост]
- ЯДРО ТД §3: L определено через проколы замкнутой поверхности — это тождественный ноль.
  Определять как зацепление кольца с образующей окружностью 2D-носителя. К правке.

Спин как период P (наш аналог, не классический):
| квант | переворот | P | спин P/2 [мост] |
| Q1 | нечему | 1 | ½ |
| Qν | запрещён непроникновением | 1 | ½ |
| Qf | свободен: +− ↔ −+ | 2 | 1 |
Запрет не создаёт полуцелость — он не даёт Qν стать как Qf. Z, W, глюон, карусели — P = 2.

λ-молекулы — аккумуляторы вращения, не «клей»:
- Один объект с параметром n (число осей): Z (1), W (2), глюон (3); 2ⁿ звеньев; цикл; чётно;
  ровно три. [Д]
- 4 места на тор. Свободно: Z — 3 на тор (соосные кольца на одном месте), W и глюон — 2.
- Причал не останавливает f-цепь — сворачивает её полёт во вращение сборки.
- Снежинка цела: одно ω на всю сборку, ω ≤ c/R_max. Запас W ∝ ω·Σ r_i² по клеткам паттерна
  (клетки Q0 — вес ноль). Ёмкость ограничена сверху; значение ω — [О].
- R₀ зависит от ядра: R₀(Z) < R₀(W) < R₀(глюон). Z — ёлка вокруг оси пары.
- Отверстие глюонного кольца вмещает три Q1 — зародыш направлений, не кварк. [Г]
- Компенсация не даёт долгой жизни: Z скомпенсирован и разряжается. Z, W — разряд.
- Две пустоты: сплошной Q0 ≠ вакуум, заполненный причалами (глюонный конденсат [мост]).

Гравитационный сектор — на паузе:
- s = s∞ + ψ (общая линейка + вращательный избыток по ячейкам). ∇²s = −k·ρ_I; гравитация = ∇s.
  Вне вещества s = s∞ + A/r. Путь гнётся к большей s (Ферма — минимум полного времени).
- T-1 сведён к T-2: свет (Q2, две ячейки) платит 2ψ при едином правиле сложения цены для источника
  и пробника. Скалярной записи мало — путь к полной картине через тензорное уравнение T_μν (O-1).
- P-7l закрыт в главном порядке: асимметрия согласования на скорости c даёт ℓv/c².
  Чтение Лоренца–Пуанкаре: выделенная система есть, изнутри не обнаружима (подтверждено Автором).

## 6. Типовые ошибки — проверять себя на каждую
- Подмена уровня — самая частая. В том числе через ссылку на результат из другого FRAME.
- Подмена точки наблюдения: вселенная-квант изнутри и снаружи; свободный и причаленный латчер.
- Двойной счёт одного явления.
- ω против I; I ячейки против I сборки.
- Сложение скоростей разных уровней в одной системе; проекция против пути.
- Сдвиг уравнения на производную: потенциал против поля.
- Источник, поле и пробник перепутаны.
- Классический смысл вместо нашего: спин через двойное накрытие, масса как первичная, «клей».
- Отверстия и промежутки — как пустота.
- ∥/⊥ прочитаны как положение, а не как оси вращения.
- Подгонка чисел; совпадение числа принято за механизм.
- Снять порученную задачу самовольно — или вернуть её без нужды.
