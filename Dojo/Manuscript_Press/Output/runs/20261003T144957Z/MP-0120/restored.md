A substantial body of literature conceptualizes multi-agent systems within language models. These systems feature several agents, each embodying distinct roles, interacting through implemented communication channels. Notable examples include CAMEL (Li et al., NeurIPS 2023), MetaGPT (Hong et al., ICLR 2024), ChatDev (Qian et al., ACL 2024), AutoGen (Wu et al., COLM 2024), and Generative Agents (Park et al., UIST 2023). Each of these implementations exhibits genuine agent-to-agent interaction within software, encompassing orchestration, message passing, tool invocation, and memory management. While mechanisms diverge, several notably codify roles and interaction patterns directly within prompts: CAMEL utilizes inception prompting, MetaGPT embeds standard operating procedures in prompt sequences, and AutoGen blends natural language with code. A unifying characteristic of these systems is not the avoidance of prompts but the execution of the described interactions within the software itself. The closest published parallel to this framework is the Virtual Lab (Swanson et al., Nature), where a human researcher collaborates with a team of LLM agents on a genuine scientific challenge, employing structured individual and team interactions. Crucially, the Virtual Lab's interaction dynamics are also implemented programmatically.
