# Temporal — Лабораторное пространство HONC

Эта папка содержит необработанные или находящиеся в работе материалы.
Перенос отсюда в HONC требует каталогизации и создания YAML-манифеста.

## Правила
- Материалы в `books/` — исходные тексты теории.
- Материалы в `experiments/` — рабочие зоны для Claude-Экспериментатора.
- После переноса в HONC файл удаляется из Temporal или перемещается в `archive/`.
