# Глава 3. Динамика в ВПК-модели: от дискретных операторов к взаимодействиям

В строгом классическом формализме дифференциальные операции, такие как ∂/∂x или dt/dx, не вводятся; вместо них используются конечные разности на решётке λ как следствие постулата №3 (масштабируемость пространства). Данная глава развивает математический аппарат для описания динамических процессов в дискретном пространстве квантронов, выводя уравнения движения из топологических свойств микроконтинуумов без привлечения внешних полей.

## 3.1 Дискретная производная и роторные операторы на решётке квантронов

В соответствии с аксиомой дискретности пространства (раздел 1.1), все дифференциальные операции заменяются конечными разностями на решётке квантронов с масштабом λ.

**Блок определений: Оператор дискретной производной**

∇μ f(n) = [f(n + êμ) - f(n)] / λ

где êμ — базисные векторы кубической решетки с |êμ| = 1, направления: ê₁ = (1,0,0), ê₂ = (0,1,0), ê₃ = (0,0,1). Размерностный анализ: [∇μ f] = [f]/λ, где λ имеет размерность [L], обеспечивая корректный переход к классическому пределу.

Связь с топологией квантрона: направления êμ определяются кристаллографической структурой решетки и ориентацией осей микроконтинуума, но не принадлежат непосредственно фундаментальной группе π₁, которая характеризует внутренние петли и циклы.

**Блок определений: Ротор на решётке**

Для тензора второго ранга ротор определяется как:
(∇ × T)ᵢ(n) = εᵢⱼₖ ∇ⱼ Tₖₘ(n)

где εᵢⱼₖ — символ Леви-Чивиты для 3D-пространства; размерность [rot T] = [T]/[L] = [M L⁻² T⁻²]. В дискретном представлении:

(∇ × T)ᵢ(n) = εᵢⱼₖ [Tₖₘ(n + êⱼ) - Tₖₘ(n - êⱼ)] / (2λ)

Для пространств размерности D < 3 используются соответствующие проекции: εᵢⱼ для 2D, сохраняя антисимметрию без "урезания" 4D-символа.

Такой оператор применяется к латчерам и протокваркам, создавая градиенты поля времени без внешних источников, что эквивалентно макроскопическим взаимодействиям в рамках постулата топологических трансформаций (раздел 1.4).

## 3.2 Формулировка тензора поля времени T_μν для различных топологий

Тензор T_μν строится как агрегат на решётке, определяемый топологией микроконтинуумов и их иерархической организацией согласно аксиоме иерархии (раздел 1.1). Для квантрона Q с топологическим типом T:

T_μν(Q) = τ n_μ n_ν + A_μν

где τ — плотность энергии времени с размерностью [τ] = [M L⁻¹ T⁻²], согласованной с предыдущими главами; n_μ — топологический вектор (безразмерный), определяемый ориентацией осей микроконтинуума; A_μν — антисимметричная часть, возникающая из нетривиальных циклов π₁.

**Иерархическое масштабирование:**

T_μν^(n) = k^n T_μν^(0) + Λ_μν^связка

где k = α⁻¹ ≈ 137.036 — масштабный коэффициент; Λ_μν^связка — тензор межквантронных связей с размерностью [M L⁻¹ T⁻²], обеспечивающий эмерджентное поле времени на высших уровнях иерархии.

### 3.2.1 Классификация T_μν по топологическим типам

**Q₀ (3D-шар, S³):**
π₁ = {e} (тривиальная группа)
A_μν = 0, T_μν = τ g_μν
Только гравитационный компонент, антисимметричная часть отсутствует из-за отсутствия нетривиальных циклов

**Q₁ (протокварки, композиция 1D+2D):**
π₁ ≃ ℤ (определяется кольцевой компонентой)
A_μν = 0, T_μν симметричен
Гравитация плюс осевое взаимодействие, реализующее структуру вкуса/цвета

**Q₂ (латчеры, смещённый 1D+2D):**
π₁ = ℤ × ℤ (торовая топология определяет два независимых цикла)
A_μν ≠ 0
Полная структура взаимодействий с "суперклеящей" латч-связкой

**Q₃ (3×1D, нестабильная конфигурация):**
π₁ зависит от способа соединения колец
T_μν содержит градиенты распада, описывающие топологическую нестабильность

## 3.3 Вывод уравнений движения из вариационного принципа

Динамика следует из лагранжиана на дискретной решетке в соответствии с постулатом многокомпонентного поля времени (раздел 1.3).

**Блок определений: Дискретный лагранжиан**

L = Σᵢ λ³ [(∂φ/∂t)² - c²(∇\_λφ)² - V(φ)] / 2

где λ³ — объем кванта пространства; размерность [L] = [M L T⁻²] (действие/время); все слагаемые имеют одинаковую размерность [M L⁻¹ T⁻²]. Альтернативная форма через тензорные инварианты:

Λ = a T_μν T^μν + b φ² + V(φ)

где коэффициенты a, b подобраны для обеспечения [Λ] = [M L⁻¹ T⁻²].

**Вариационный принцип в дискретном виде:**

δS = δ Σₙ [Λ(n) λ³ τ₀] = 0

где суммирование ведется по всем узлам решетки, τ₀ = λ/c — временной квант из раздела 1.1.

**Блок определений: Уравнения движения**

Минимизация действия приводит к дискретному волновому уравнению:

∂²φ/∂t² - c²∇²_λφ + ∂V/∂φ = 0

где ∇²_λ — дискретный лапласиан:
(∇²_λφ)ᵢ = Σ_μ [φ(xᵢ + λêμ) + φ(xᵢ - λêμ) - 2φ(xᵢ)] / λ²

Скалярное поле φ ассоциировано с топологическим состоянием квантрона, [φ] = [M L⁻¹ T⁻²] (плотность энергии).

**Потенциал топологических трансформаций:**

V(θ) = k(1 - cos θ)

где θ — параметр, характеризующий ориентацию осей микроконтинуума. Минимум потенциала достигается при θ = 0 (cos θ = 1), что соответствует параллельной ориентации осей и нейтральной конфигурации q = 0. Для латчера это обеспечивает движение за счет внутренних градиентов поля времени.

## 3.4 Связь с численной симуляцией и наблюдаемой физикой

Симуляция переходов между квантронными состояниями использует дискретные операторы с характерной точностью ε = 10⁻⁸. Временной шаг выбирается как Δt = λ/c, что обеспечивает причинность и согласуется с масштабным коэффициентом континуумов. Все вычисления основаны на конечных разностях без введения производных типа dt/dx.

**Пример дискретного решения:** Для потенциала V(θ) = k(1 - cos θ) инициализируется θ = 0, затем итеративно применяется разностная схема:
θ(t + Δt) = 2θ(t) - θ(t - Δt) - (Δt)² ∂V/∂θ

Физическая интерпретация связывает модель с наблюдаемыми явлениями: протокварки (Q₁) дают поколения частиц, латчеры (Q₂) реализуют точечные взаимодействия, 3D-шары (Q₀) составляют темную материю.

**Предсказания, отличающие модель от Стандартной:**


| Предсказание | Энергетический масштаб | Экспериментальный тест |
| :-- | :-- | :-- |
| Дискретные поправки | E ~ ħc/λ ≈ E_Planck | Космические лучи Pierre Auger |
| Топологические резонансы | Без новых полей | MoEDAL поиски |
| Анизотропии спектров | α(E) ≈ sin(k E / E_Pl) | LHC высокие энергии |

Дискретные поправки проявляются при энергиях E ~ ħc k / ℓ_P ≈ E_Planck ≈ 10¹⁹ ГэВ, существенно превышающих возможности LHC (14 ТэВ), но доступных в космических лучах сверхвысоких энергий.

**Формула анизотропии:**

Δ(φ,θ) = (L/λ) N₀ cos α

где L — характерный размер области наблюдения, N₀ — нормировочная константа с размерностью потока [T⁻¹]. Дискретные пики проявляются при энергиях:

E_peak = n ħc/λ, где n = 1, 2, 3, ...

## Заключение Главы 3

Все динамические уравнения ВПК-модели являются прямым следствием дискретности пространства, топологических свойств микроконтинуумов, иерархического масштабирования и лагранжиановых вариационных принципов, установленных в аксиомах 1.1–1.4. Модель выводит фундаментальные взаимодействия исключительно из геометрии квантронов без привлечения внешних полей, предсказывает проверяемые отклонения от Стандартной модели в области сверхвысоких энергий и обеспечивает единый математический формализм для описания всех типов квантронных трансформаций в строго классических терминах конечных разностей на дискретной решетке.

# Глава 3. Динамика в ВПК-модели: от дискретных операторов к взаимодействиям

## 3.1 Дискретная производная и роторные операторы на решётке квантронов

В соответствии с аксиомой дискретности пространства (раздел 1.1), все дифференциальные операции заменяются конечными разностями на решётке квантронов с масштабом λ. Это усиливает связь с предыдущими главами без повторений основополагающих принципов.

**Блок определений: Оператор дискретной производной**

∇μ f(n) = [f(n + êμ) - f(n)] / λ

где êμ — базисные векторы кубической решетки с |êμ| = 1, направления: ê₁ = (1,0,0), ê₂ = (0,1,0), ê₃ = (0,0,1). Размерностный анализ: [∇μ f] = [f]/λ, where λ имеет размерность [L], обеспечивая корректный переход к классическому пределу.

Связь с топологией квантрона: направления êμ определяются кристаллографической структурой решетки и ориентацией осей микроконтинуума, но не принадлежат непосредственно фундаментальной группе π₁, которая характеризует внутренние петли и циклы.

(∇ × T)ᵢ(n) = εᵢⱼₖ [Tₖₘ(n + êⱼ) - Tₖₘ(n - êⱼ)] / (2λ)

Для пространств размерности D < 3 используются соответствующие проекции: εᵢⱼ для 2D, сохраняя антисимметрию без "урезания" 4D-символа.

Такой оператор применяется к латчерам и протокваркам, создавая градиенты поля времени без внешних источников, что эквивалентно макроскопическим взаимодействиям в рамках постулата топологических трансформаций (раздел 1.4).

## 3.2 Формулировка тензора поля времени T_μν для различных топологий

T_μν(Q) = Σ\_{соседи} τ n_μ n_ν + A_μν

S_stat = Σ_узлов [ (∇\_λ θ)² + V(θ) ] λ³, V(θ) = k (1 − cos θ)

Линеаризация по малым δθ дает матрицу колебаний, откуда фундаментальная частота:\
ω₀² ≈ (1 / I_eff) · ∂²E/∂θ² |\_{θ=θ₀}

Теорема №11 «Геометрическая оценка массы кластерного основного состояния»\
Исходные данные уровня: λ = k · ℓ_P; геометрия — равносторонняя триада узлов (Q₁) с латчерной связкой по ребрам. В безразмерной нормировке по «массе кванта» момент инерции триады (относительно центра масс) оценивается формулой I ~ λ² / C, где C зависит от предусматриваемого распределения (для точек в вершинах равностороннего треугольника C лежит в интервале 3–6; точное значение фиксируется конфигурацией связей и нормировкой масс узлов). Сеточный лапласиан на трех узлах с циклическими граничными условиями задает базовую частоту порядка ω₀ ~ c / λ с численным коэффициентом порядка единицы (конкретное значение определяется спектром разностного оператора для выбранной геометрии). Энергия основного колебательного режима E₀ ~ (1/2) I ω₀² задает масштаб кластерной массы m₀ через m₀ c² ~ E₀.

Пояснение о численных коэффициентах\
Все численные коэффициенты (включая конкретные значения вроде «0.78») зависят от выбранной дискретной схемы и нормировок и должны обосновываться отдельно (предлагается вынести в приложение с расчетами). В основном тексте оставляется размерностно корректная форма, подчеркивающая геометрическую природу оценки. Прямые заявления уровня «совпадение 0.01%» убраны из тела главы и допустимы только в приложении при предъявлении полной расчетной цепочки и погрешностей.

Колебательные резонансы\
Резонансные колебания кластера описываются как m_res ≈ m₀ · (1 + δ), δ ∈ [0.2, 0.4], в зависимости от граничных условий и мод локальных латчерных связей (N, Δ-подобные возбуждения без введения внешних полей).

## 4.4 Тёмная материя как Q₀-конденсат уровня IV

Q₀ — 3D-шар (S³) с A_μν = 0 (антисимметричная часть отсутствует), энергетика определяется симметричной компонентой T_sym. Конденсация Q₀-кластеров описывается порогом перколяции по узлам (эвристически p_c ≲ 0.31 для кубической решетки) и локальной стабилизацией (∂²V/∂θ² |\_{θ=0} > 0). Плотность энергии конденсата: ρ_Q0 ≈ τ_Q0 (размерность M L⁻¹ T⁻²). При критической плотности ρ_crit и наблюдаемой Ω_DM ≈ 0.26 число Q₀ на объем λ³ оценивается как:\
n_Q0 ≈ (Ω_DM ρ_crit / τ_Q0) · λ³\
что соответствует «разреженному» заполнению, согласующемуся с чисто гравитационным проявлением и отсутствием электромагнитных сигнатур.

## 4.5 Космологические следствия

- Ранняя Вселенная (a → 0): доминирование симметричной части T_sym дает эффективное уравнение состояния уровня релятивистского газа p ≈ ρ/3 (в рамках допущений дискретной модели).
- Спектр первичных гравитационных волн: h_c(f) ∝ k⁻¹ (λ f)⁻², пиковая частота f_max ≈ c / (2π λ) (дискретный спектр мод).
- Порог GZK: E_max ≈ (m_Pl c²) / k; дискретные пики при E_n ≈ n (ħ c / λ) — ожидаемые подписи дискретности масштаба λ в спектрах космических лучей сверхвысоких энергий.

## 4.6 Экспериментальная верификация

- LHC / FCC: прямой доступ к энергии ħ c / λ недостижим (14–100 TeV ≪ ħ c / λ), но возможны косвенные проявления дискретности (аномальные угловые корреляции, редкие многозарядные треки от латчер-кластеров).
- MoEDAL: отсутствие свободных монополей согласуется с A_μν-структурой; целевые сигнатуры — треки с нетипичной ионизацией и «ступенчатой» топологией, соответствующей латчерным связям.
- Pierre Auger: ожидаются дискретные пики/полосы в диапазоне (10¹⁸–10²⁰) eV; трехполосная структура может соответствовать кластерам (Q₁)\_n при n = 2, 3, 6.

# Глава 5. Ответы на дополнительные вопросы

## 5.1 Тёмная энергия как эмерджентная сумма иерархий

Механизм: на уровне n поле времени масштабируется как T_μν^(n) = k^(-n) T_μν^(0); суммирование по уровням дает конечный вклад эффективной «мягкой» подложки:

T_μν^(eff) = Σ\_{n=0}^{N} k^(-n) T_μν^(0) = T_μν^(0) · (1 − k^(-(N+1))) / (1 − k⁻¹)

Плотность энергии темной компоненты определяется симметричной частью:\
ρ_DE^(eff) ∝ Tr[T_sym^(eff)]\
Размерностно: [ρ_DE] = M L⁻¹ T⁻². Численные оценки выносить в приложение; в тексте фиксируется механизм конечной геометрической суммы и неизбежность положительного остаточного вклада без введения отдельной космологической константы.

Пояснение: вклад высоких уровней быстро убывает (~k⁻ⁿ), что обеспечивает малую, но ненулевую эффективную ρ_DE.

## 5.2 Квантовая гравитация как дискретная коррекция к T_μν

Планковский предел реализуется через минимальный шаг λ и временной квант τ₀ = λ/c. Флуктуации поля времени на узле n:

ΔT_μν^(n) ~ ξ · T_μν^(n), |ξ| ≪ 1 (стохастический, дискретный)

Модифицированные уравнения гравитации в дискретной форме:

G_μν[λ] = κ · ⟨T_μν⟩\_λ + κ_q · Var_λ(T_μν)

где ⟨·⟩\_λ — среднее по окрестности размера λ, Var_λ — дискретная дисперсия. κ, κ_q — константы связи (безразмерные в принятой нормировке), задаваемые иерархией. Сингулярности заменяются топологическими переходами (переклейка узлов в классы, сохраняющие χ и структуру π₁), что устраняет бесконечности на уровне решетки.

Экспериментальные следствия формулируются дискретно:

- отклонения от ОТО проявляются при длинах ~λ (выше доступного диапазона ускорителей);
- дискретная структура горизонта черной дыры задает конечное число микросостояний N_states (энтропия S ~ ln N_states) без непрерывных интегралов по полям;
- разрешение сингулярностей — как смена клеточной конфигурации с сохранением топоинвариантов.


## 5.3 «Серая зона»: кристаллография ансамблей и коллективные моды

Определение: «Серая зона» — область больших ансамблей квантронов N ~ 10²³–10³⁴, где эффективная физика возникает из кристаллографических свойств решетки. Здесь стандартные спектры и массы — следствие коллективных мод (фононоподобных) в дискретной среде.

Математическая постановка (дискретная):

- Решетка: симметрия G_cryst = SO(3) × T_λ (трансляции на шаг λ).
- Энергия ансамбля: H = Σ_i H_i + Σ\_\<ij> V_ij, где H_i — локальная энергия квантрона (см. теоремы главы 2), V_ij — взаимодействие соседей (латчерная связность) масштаба ~ c²·τ·λ³ (размерностно M L² T⁻²).
- Нормальные моды: дискретное преобразование по решетке (аналог Фурье) приводит к дисперсии типа\
ω²(q) = ω₀² + 2α · [3 − cos(q_x λ) − cos(q_y λ) − cos(q_z λ)]\
с обрезанием на q ~ π/λ. Массы эмерджируют как E/c² из ω(q≈0).

Теорема №12 «Эмерджентные массы из коллективных мод»\
Массы наблюдаемых частиц в «серой зоне» соответствуют низкочастотным модам дискретного спектра ансамбля; различия лептон/барион обусловлены различными эффективными конфигурациями и числом связей на узел.

Теорема №13 «Кристаллография и зонная структура»\
Запрещенные зоны ΔE формируются из сильной связи на решетке квантронов; их масштаб ~ c ħ / λ по порядку величины. Это объясняет наличие дискретных пиков в космических лучах на сверхвысоких энергиях как зонные эффекты кристалла квантронов.

Комментарий: Все выводы выражены суммами по узлам/соседям; непрерывные интегралы не применяются.

- Топологический инвариант — величина, сохраняемая при непрерывных деформациях (π₁, χ и т.п.).

## Примеры точечных замен

- Раздел «Дробные заряды (Вопрос 11)»\
Заменить: q = (χ/2) · sgn(det π₁)\
На: q = (n₁ − n₂)/3, со знаком через ориентационный инвариант Ω = ±1; det π₁ не определён, использовать топологическую ориентацию циклов тора (T²).[^12_1]
- Раздел «SU(3) (Вопрос 12)»\
Смягчить: «алгебра Каца–Муди уровня k=3…»\
На: «двухцикловая структура π₁(T²) = ℤ × ℤ порождает естественную трёхкомпонентную базисную структуру (цветов), соответствующую SU(3) в эффективном описании; детали алгебраической конструкции — в приложении».[^12_1]
- Раздел «Темная энергия (15–16)»\
Заменить «точно соответствует наблюдаемой ρ_DE»\
На: «даёт малую, но конечную ρ_DE; численное согласование требует выбора шкалы суммирования и проверяется на данных; без введения отдельной Λ».[^12_1]
- Раздел «Монополи (23)»\
Заменить «топологически невозможны»\
На: «не реализуются как изолированные объекты при данной структуре A_μν; ожидаются связанные вихревые конфигурации; это согласуется с отсутствием детекций».[^12_1]
- Раздел «Сила (60)»\
Переписать: F_L = ∫ (∇ × T) × v dV\
На: F_i ∝ Σ_ячейкам v_j [∂\_i T_jk − ∂\_j T_ik] λ³, как дискретная форма «силы Лоренца» в терминах антисимметричной части T_μν (без полевых переносчиков).[^12_1]
