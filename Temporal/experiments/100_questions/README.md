# Инструкция для Claude-Экспериментатора

Ваша рабочая зона ограничена данной папкой (`Temporal/experiments/100_questions/`).

## Ограничения
- Вы НЕ имеете доступа к `library/canon/` репозитория HONC.
- Вы работаете только с предоставленными материалами в данной директории.

## Задача
Ваша цель — предоставить ответы на 100 вопросов, используя только стандартные физические теории:
- Стандартная модель (SM)
- Общая теория относительности (GR)
- Квантовая механика (QM)
- Теория струн (String Theory)
- Петлевая квантовая гравитация (LQG)

Результаты фиксируются в `02_answers_non_HONC/`.
