### 2. Исправить

#### 2.1. B6 (ii) — «путь не запрещён локально; продевание через касп не нарушает НП»

**Неверно.** Здесь смешаны допустимость **конечной конфигурации** (латчер допустим) и допустимость **события** — перехода в неё.

**Контрдовод рецензента.** В плоскости z = 0 тело занимает 0 ≤ ρ ≤ 1, а открытое тело — это 0 < ρ < 1. Значит, рядом с каспом единственная допустимая точка плоскости z = 0 — **сам касп**. Отсюда:
- Нить кольца, идущая из верхней воронки в нижнюю, пересекает z = 0 только в каспе.
- Чтобы нить **начала** проходить через касп, ей нужно пройти z = 0 дважды (вниз и обратно вверх) — и оба раза в одной точке. Для вложенного кольца это невозможно.
- Значит, число трансверсальных проходов через касп (= L) локально постоянно на допустимом пространстве. Сохраняющиеся носители: вложенное кольцо, стянутый тор, НП II.1.

Итог: **в классе (ii) пути Q1 → Q2 тоже нет.** Касп — точечное «горлышко». Продевание через касп — не непрерывное движение сохраняющихся носителей. Это событие вне E1/(ii): самопересечение кольца, вход в открытое тело или смена типа носителя (раскрытие каспа). Закон его — П1 [О].

Отдельно: фраза «встреча с осевой окружностью … локализована геометрически (касп)» смешивает окружность и её диск. Касп лежит на **диске**, натянутом на осевую окружность. Сама окружность находится при ρ = ½, внутри тела.

**Требуется:** оформить это как теорему с доказательством. Это твой результат, я дал только ключевой факт. Затем исправить B6, D2.6 и формулировку «минимального события».

#### 2.2. B3 / D2.5 — «осевая окружность — единственная естественная окружность, не пересекающая кольцо латчера»

**Неверно.** Все невырожденные **параллели** поверхности рогатого тора тоже не пересекаются с кольцом латчера, включая внешний экватор: кольцо касается поверхности только в каспе.

**Численная проверка рецензента** (кольцо латчера через касп, касательное к оси):

| Окружность | L | Мин. расстояние |
|---|---|---|
| осевая (ρ = ½, z = 0) | −1 | 0,5 |
| внешний экватор | −1 | 1,0 |
| параллель ρ = 0,2 | −1 | 0,106 |
| параллель ρ = 0,8 | −1 | 0,553 |

Объяснение: горизонтальная окружность (ρ, z) встречает кольцо только на кривых ρ = 1 ∓ √(1 − z²). Все параллели лежат по ту же сторону, что осевая окружность, поэтому изотопны ей в дополнении кольца.

**Верная формулировка сильнее твоей:** L не зависит от выбора среди окружностей долготного типа, а меридианы исключены — все проходят через касп. Выбор F2 содержательно не условен.

#### 2.3. Ч.1 §0, самопоправка о сфере: «r < R — вход в ограниченный шар»

**Неверно.** II.1 — правило «не переходить на другую сторону 2D-носителя». Для тора это означает «не входить в тело». Для сферы-оболочки кольцо внутри ячейки сферу не пересекает. Значения r ≠ R исключает A-5 (длина кольца 2πR), а не НП.

Перефразировка «запрещена открытая область, ограниченная 2D-носителем» верна только для тора.
