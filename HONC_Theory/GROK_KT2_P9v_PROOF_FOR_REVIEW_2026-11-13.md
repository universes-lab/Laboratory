## 0. Построение — что именно доказывается

**Рамка и нить:**
- общая рамка (e_x, e_y, e_z);
- торы нити: центры A_k = A_0 + 2k·e_z, ось каждого — вектор e_y, одинаково ориентированный;
- рогатый тор R = r = ½ как множество задаётся центром и **прямой** оси;
- навес на хозяине h — параметры (s, ρ, ψ, δ).

**Правила построения** (интерфейс v6, § 2, М-14; поправка G-2 к спецификации):

- **(К1) Направление:** e = s·cos ρ·e_x + sin ρ·(−cos ψ·e_z + sin ψ·e_y).
- **(К2) Ось навеса.** T′ = T_h − 2(T_h·e)·e, где T_h = e_y — ось хозяина. Затем T′ поворачивается на δ вокруг n_e = норм(e × T_h) по правилу правой руки:
  T_H = T′·cos δ + (n_e × T′)·sin δ.
- **(К3) Расстояние центров:**
  - при δ = 0 — закрытая форма d = 1 + √(1 − (e_y·e)²);
  - при δ ≠ 0 — корень G-4(T_h, H(d)) = 0, единственный на [0; ∞).
- **(К4) Центр навеса:** A_H = A_h + d·e.
- **(К5) Кольцо RH** (G-2):
  - плоскость — A_h + span(e, e_y);
  - в ней пучок коник через A_h и A_H, касательных к прямым A_h + t·pr(e_y) и A_H + t·pr(T_H), где pr — ортогональная проекция на плоскость;
  - член пучка с длиной 2π единствен: длина строго растёт по μ.
- **(К6) Уравнение касания** `fix`: F(ρ) = G-4(T_{h−1}, H(ρ)) = 0 на вилке [a; b]. Ядро удостоверяет существование и единственность корня на вилке, иначе навес — `UNRESOLVED`.
- **G-4** — зазор тор–тор: g = dist(C₁, C₂) − 1, где C₁, C₂ — средние окружности, расстояние между множествами.

## 1. Плоскость кольца при δ ≠ 0 и её нормаль

По (К5) плоскость кольца — A_h + span(e, e_y) **при любом δ**. Ось T_H входит только через свою проекцию: касательная прямая в A_H.

Нормаль:

n ∝ e × e_y = s·cos ρ·e_z + sin ρ·cos ψ·e_x.

- Ни sin ψ, ни δ в неё не входят.
- Кольцо не вырождено, только если e не параллельно e_y, то есть не (ρ = 90° и cos ψ = 0). Иначе кольцо не строится — ядро даёт ошибку «ось неотделима от хорды», и правило не применяется.

**Зависимость:** п. 1 держится на определении G-2 для T_H вне плоскости (s, e_y). Если ты читаешь G-2 иначе, п. 1 падает. Укажи это.

## 2. Зеркальное отображение и совпадение корней `fix`

**Отображения:**
- S — отражение в плоскости через ось нити, натянутой на e_x и e_z: S(P) = P − 2((P − A_0)·e_y)·e_y. На векторах S·e_y = −e_y, S·e_x = e_x, S·e_z = e_z.
- τ — перенос на 2m·e_z, m = h′ − h > 0.
- Навес H = H(h; s, ρ, ψ, δ), зеркальный навес H* = H(h′; s, ρ, −ψ, −δ).

**Л1. Симметрия нити.**
- S и τ коммутируют: e_z лежит в плоскости зеркала.
- S переводит каждый тор цепочки в себя: центр — в плоскости зеркала, прямая оси e_y перпендикулярна ей.
- τ переводит T_k в T_{k+m}, если k и k + m — в одной цепочке общей рамки: оси равны, шаг — 2e_z.
- **Посылка:** T_{h−1}, T_h, T_{h′−1}, T_{h′} — в одной цепочке, и ось хозяина — один и тот же вектор e_y у h и h′.

**Л2. Перенос построения.** Для **каждого** ρ: H* = τS(H) как множество. По пунктам:
- **(а)** e* = S·e — у S·e меняется только составляющая вдоль e_y, то есть знак sin ψ.
- **(б)** Ось:
  - e_y·e* = (S·e_y)·e = −e_y·e, поэтому T′* = e_y + 2(e_y·e)·S·e = −S·T′;
  - для отражения S(a) × S(b) = −S(a × b); отсюда e* × e_y = −(S·e × S·e_y) = S(e × e_y), то есть n_e* = S·n_e;
  - T_H* = T′*·cos δ − (n_e* × T′*)·sin δ = −S·T′·cos δ + (S·n_e × S·T′)·sin δ = −S·(T′·cos δ + (n_e × T′)·sin δ) = −S·T_H.

  Прямая оси та же. Ориентация оси хозяина при этом общая, e_y у h и h′, — это существенно: смена знака T_h меняет смысл δ.
- **(в)** d* = d:
  - при δ = 0 — (e_y·e*)² = (e_y·e)²;
  - при δ ≠ 0 — G-4(T_{h′}, H*(d)) = G-4(τS·T_h, τS·H(d)) = G-4(T_h, H(d)) **при всех d ≥ 0**. G-4 — функция двух множеств: она инвариантна при любой изометрии, включая отражение, и не зависит от ориентации осей. Нули совпадают, единственность на [0; ∞) переносится.
- **(г)** A_H* = A_{h′} + d·S·e = τS(A_h + d·e), так как S(A_h) = A_h.

**Л3. Корни `fix`.** При `fix` с T_{h−1} и T_{h′−1}:

F*(ρ) = G-4(T_{h′−1}, H*(ρ)) = G-4(τS·T_{h−1}, τS·H(ρ)) = F(ρ) **тождественно по ρ**.

Это равенство функций, не чисел. Следствия:
- **Множества корней** на общей вилке [a; b] совпадают, вместе с кратностями.
- **Неоднозначные корни.** Если на вилке у F несколько корней, у F* — те же. Ядро тогда не удостоверяет единственность ни у одного навеса, оба `UNRESOLVED`, правило не применяется.
- **Выбор ветви.** Он делается в трёх местах:
  - вилка `fix` — одна и та же во входе (посылка);
  - корень d при δ ≠ 0 — единствен на [0; ∞);
  - член пучка колец — единствен.

  Других ветвей в построении нет.
- **Общая вилка.** Обе вилки ядра содержат один и тот же истинный корень. Значит, их оболочка — верная вилка, как в П-8(г). Пересечение тоже было бы верным, оболочка — осторожнее.
- **Удостоверение корня** по-прежнему требуется у каждого навеса отдельно.

**Л4. Кольцо.**
- Данные (К5) для H* — образы τS данных для H: плоскость, точки A, A_H, две касательные прямые. Проекция коммутирует с S: S переводит плоскость в плоскость.
- Кольцо G-2 по этим данным единственно, поэтому RH* = τS(RH).
- Нормаль n не имеет составляющей вдоль e_y, значит S·n = n. **Плоскости RH и RH* параллельны тождественно.**

## 3. Расстояние между плоскостями и строгая положительность

Обе плоскости проходят через центры хозяев: кольцо идёт через A_h. Отсюда

dist = |n·(A_{h′} − A_h)| = 2m·|n·e_z| = 2m·|cos ρ| / √(cos² ρ + sin² ρ·cos² ψ).

При m > 0 расстояние строго положительно тогда и только тогда, когда cos ρ ≠ 0. Запись:
- **вилка dist > 0** — `parallel-distinct`, R-3, `EXACT`;
- **ρ = 90° точно во входе** — dist ≡ 0, одна плоскость, R-4 со своими проверками;
- **вилка, содержащая 0, но не тождественный ноль** (вилка корня ρ накрывает 90°) — `UNRESOLVED`, как сейчас R-5. `PASSED` здесь не выдаётся.

## 4. Область правила и ложный `PASSED`

**Посылки — исчерпывающе:**
- **В1.** Хозяева h < h′ и торы T_{h−1}, T_{h′−1} (при `fix`) — в одной цепочке общей рамки (звенья θ = 0, δ = 0, П-2, П-3); векторы рамки и оси хозяев равны.
- **В2.** Одна сторона s.
- **В3.** Координаты ρ–ψ; свободный параметр — ρ или нет свободного.
- **В4.** ψ + ψ′ ≡ 0 (mod 360°) — точно, по числам входа.
- **В5.** δ′ = −δ — точно.
- **В6.** ρ одинаково: либо одно число во входе, либо `fix` с T_{h−1} и T_{h′−1} при одной вилке и удостоверенных корнях обоих.

**Чего правило не утверждает:**
- **Класс оси (`tClass`) не объединяется.** T_H* = −S·T_H параллельна T_H, только если T_H ⊥ e_y или T_H ∥ e_y.
- **Касание и разделение навес–навес** — только G-4.
- **J5, защёлки** — правило о них ничего не говорит.
- **Статус** [Д-Кл] утверждения источника не меняется.

**Вне правила:**
- разные стороны;
- координаты α–λ;
- свободный ψ;
- `fix` с другими торами или разными вилками;
- хозяева в разных цепочках;
- наклонные звенья нити;
- ψ′ ≡ −ψ при δ′ ≠ −δ. Нормаль от δ не зависит, но равенство корней ρ тогда не доказано. Случай одного числа ρ при разных δ сюда сознательно не включён.

**Откуда мог бы взяться ложный `PASSED`?** Только из R-3, выданного для плоскостей, которые на деле не параллельны или не различны.
- Параллельность — тождество Л2–Л4.
- Различность — удостоверенная вилка > 0.
- Различные параллельные плоскости — кольца не пересекаются, и это R-3 по v7, § 4.

**Сторож в реализации.** Ядро по-прежнему строит оба кольца независимо. Если вилки их нормалей не пересекаются — `kernel_error`, а не `PASSED`. Расхождение тождества с вычислением означает ошибку в коде.
