```text
FRAME: QUANTRON | INSIDE_CURRENT_CONTINUUM | frame
QUESTION: Как устроен квантрон — «государство» граждан одного Q-типа — и что из устройства гражданина задаёт его законы?
```

**Короткий ответ.**
- Гражданин разобран настолько, насколько это нужно для перехода. Его открытые развилки государство не блокируют, они отложены (п. 3).
- «Государство» в каноне названо прямо: квантрон — облако одного Q-типа (K4) в среде, которую заполняют причаленные цепи и глюонная среда (K1, G18).
- Первый вопрос предлагаю такой: какой порядок правило соседства граждан (J5: встречное вращение на контакте) навязывает всему облаку и где этот порядок неизбежно рвётся. Это родной, топологический вход в протяжённость квантрона (U-5) — без сил, без «передачи» и без метрономов.

## 1. Что такое «государство» в HONC

| Положение | Что говорит |
|---|---|
| K1 {·} | Полка: квант → λ-молекула → три параллели (короткая f-цепь на причале, жгут, квантрон-облако одного Q-типа) → облако квантронов → партон → кварк. Среда (причаленные цепи, глюонная среда) заполняет полки, отдельной ступенью не стоит |
| K4 {P} | Квантрон — облако одного Q-типа; изотропен; протяжённость зависит от состояния [К]/[Г] |
| K5 {P} | Партон — уровень, где впервые проявляется рассеяние; квантрон ≠ партон [К] |
| C3, C4 | Общая линейка одна; s = s∞ + ψ — вращательный избыток по ячейкам [Д] |
| C8, C9 | С уровня квантрона гравитация изотропна — оси усредняются [К]; тороидальные вклады не усредняются, ЭМ направлен [Д] |
| G13 | Снежинка цела: одно ω на паттерн [Г] |
| G18 | Сплошной Q0 ≠ вакуум, заполненный причалами [Д] |
| U-5 | Протяжённость квантрона — предел топологической согласованности; механизм не выписан. Ранее отложено Автором |

**Чего не делать — уроки прошлого прохода по U-5:**
- «доска = линейная компонента» снято Автором;
- синхронизация метрономов для вращательной компоненты снята: она согласуется топологически (экваториальное сцепление, J5, цикличность и чётность);
- нет слов «сила», «притяжение», «передача»;
- гравитация на паузе до O-1.

**Развилка — с рекомендацией.** Я читаю «государство» как квантрон-облако одного Q-типа: в нём живёт отдельный Q1. Если вы имели в виду адрон — протокварки в глюонной и W-среде, — начну оттуда.

## 2. Гражданин: что установлено (коротко, со статусами)

- **Тела.** Шесть типов Q1 — три тела: {Qd, Qu}, {Qs}, {Qc, Qt, Qb} [Д]. Масса — один μ, баланс по I (В1–В4) [Д].
- **Метки −1/3 и +2/3** — счёт осей, а не заряды [К].
- **Qs** — единственный торовый тип с неподвижными отверстием и кольцом. Только к нему причал стоит неподвижно [Д при В3 или кинематике Автора].
- **Связь Q1–Q2** — топологическое зацепление без касания и без замкнутой λ-молекулы [Д]. Это ещё не сопряжение (О-к).
- **Связный узел** — у всех элементов один темп (G13) [Д при П1]. Состояние проходит защёлки; пара колец узла — одно событие [Г | G12].
- **Плотность связей** — не больше трёх колец в точке (A-15) [К как ограничение].
- **Зацепление L** — отдельная топологическая величина. Заряд — по компенсации осей (R2, рабочее разграничение).

## 3. Развилки гражданина, отложенные (государство не блокируют)

- П-X — чтение «X– ↔ X+» для неколлинеарных осей.
- П-δ — A-15 в событиях или в кольцах.
- К-1 для касающихся колец.
- Двусмысленность F4.
- O-surface; кинематика Qb.
- Закон фазы.
- H-Qs заморожен.

Если вопрос государства упрётся в одну из них, это будет различающим следствием для этой развилки.

## 5. Правила уровня

- FRAME SHIFT {Q}/{λ} → {P} объявляется каждый раз. Результат гражданина переносится в государство только с правилом переноса, иначе он [Г].
- Государство — не сумма граждан. В каноне это облако и самоорганизация, а «рой» — только [метафора].
- Реестр признаков Хранителя расширить на уровень {P}: какие признаки гражданина доживают до облака. Например, L = 0 у всех Q1, класс, оси, μ.
