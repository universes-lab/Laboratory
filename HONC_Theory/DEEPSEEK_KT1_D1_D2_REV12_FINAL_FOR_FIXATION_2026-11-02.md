## Правка 2 — «ширина вилки 0» у колец по тождеству

В таблице статусов пяти карточек при `κ_min = 0.05` (rev12) была строка:

> «κ_r = 1 — кольцо по тождеству, ширина вилки 0»

**Удалена.** По § 6.5 интерфейса v6: `EXACT` не означает нулевых ширин. Кольцо по тождеству — окружность радиуса 1, но центр и полуоси — результаты арифметики с округлением наружу; ширина вилки — несколько ulp, а не ноль.

**Исправленная формулировка:**

| Карточка | Прежний статус | Обновлённый статус при κ_min = 0.05 | Комментарий |
|---|---|---|---|
| **А-1** | ОЖИДАЕТ κ_min (усл.) | **ГОТОВА**; ожидается `PASSED` (κ = 1 ≥ 0.05) | κ_r = 1, полнота `EXACT`; ширина вилки по § 6.5 — несколько ulp, не ноль |
| **А-2** | ОЖИДАЕТ κ_min (усл.) | **ГОТОВА**; `PASSED` | κ_r = 1, `EXACT`; ширина — по § 6.5 |
| **А-3** | ОЖИДАЕТ κ_min (усл.) | **ГОТОВА**; `PASSED` | κ_r = 1, `EXACT`; ширина — по § 6.5 |
| **А-4** | ОЖИДАЕТ κ_min (усл.) | **ГОТОВА**; `PASSED` (κ ≈ 0.63 ≥ 0.05) | κ_r = 1.36617 (у прежнего ядра 1.366); ширина κ_r — на полной вилке |
| **Кλ3** | ОЖИДАЕТ κ_min (усл.) | **ГОТОВА**; `PASSED` | полнота `EXACT` для К1–К3, `CERTIFIED` для К4; фактическая ширина — по § 6.5 |

Принцип, действующий для всех пяти:
- «PASSED по κ» — только по фактическим сертифицированным вилкам κ на полной вилке кольца (§ 6.5).
- Если вилка κ не отделяет κ от κ_min — `UNRESOLVED` по правилу полной вилки (`ring-enclosure`).
- `EXACT` — это уровень полноты проверки, а не нулевая ширина вилки.
