## 2. Кольцо общего вида: почему корень уравнения длины единствен

**Пучок коник.** В плоскости кольца (X = u, Y — часть T_A, перпендикулярная u) коники Q_μ = L_A·L_B − μ·y² = 0 проходят через A и B и касаются там прямых вдоль T_A и T_B при любом μ.
- При μ < μ* это эллипсы.
- Внутренность эллипса — множество Q_μ < 0: на отрезке AB знаки L_A и L_B противоположны.

**Вложенность.** При μ₂ > μ₁: Q_μ₂ = Q_μ₁ − (μ₂ − μ₁)·y² ≤ Q_μ₁. Значит, внутренность E_μ₁ лежит внутри E_μ₂.
- Периметр выпуклого множества строго растёт по включению, поэтому длина P(μ) строго растёт на (−∞, μ*).
- При μ → −∞ длина стремится к 2d < 2π, при μ → μ* — к бесконечности.
- Отсюда корень уравнения P = 2π существует и единствен. Это аналитический довод, а не выборка.

**Вилка корня.**
- Сужение пополам по знаку P − 2π; длина считается периметром AGM из WP-0.
- Когда в середине знак не определён, оба края поджимаются пробами в четвертях.
- Параметры эллипса — центр, полуоси, оси — вычисляются вилками на всей вилке μ.

**Ориентация осей.** Угол берётся от того собственного вектора, для которого atan2 далёк от разреза.
- Если почти окружность и ориентация не определена, кольцо заключается в кольцевую область: ρ ∈ hull(s1, s2) при любом t. Это верно, хотя и шире.
- Этот путь отмечается флагом `annulus`.

## 4. Точность колец общего вида — находка, вынесенная Интегратору

G-2 требует «ошибка ≤ 10⁻¹²». В двойной точности с вилками удостоверяемая точность кольца общего вида такова:

| Звено | Ширина вилок полуосей | Ширина вилки невязки длины | Отличие Рамануджана от 2π |
|---|---|---|---|
| θ = 30°, φ = 90° | 1,1·10⁻¹² / 1,3·10⁻¹² | 7,8·10⁻¹² | 5,7·10⁻¹⁴ |
| θ = 60°, φ = 90° | 3,1·10⁻¹² / 6,2·10⁻¹² | 3,0·10⁻¹¹ | −5,9·10⁻¹² |
| θ = 75°, φ = 90° | 4,3·10⁻¹² / 2,0·10⁻¹¹ | 8,1·10⁻¹¹ | −4,1·10⁻⁹ |
| θ = 85°, φ = 90° | 1,3·10⁻¹¹ / 5,1·10⁻¹⁰ | 2,0·10⁻⁹ | −3,1·10⁻⁶ |

Верность вилок это не затрагивает: истинная невязка равна нулю, и каждая вилка её содержит. Ограничение — в обусловленности цепочки формул при вилках входа шириной около 10⁻¹⁴.

**Без ограничения:**
- кольца по тождеству (К1, К2, К3) — `EXACT`;
- d по закрытой форме — ширина около 10⁻¹⁴;
- примитив периметра — около 3·10⁻¹⁴.

Все численные критерии КТ-1 (§ 2.11) грубее на много порядков.

**Последствие для набора.** Мутант м1 на уровне кольца различим только у вытянутых колец — там, где отличие Рамануджана больше ширины вилки, при θ ≳ 75°. На уровне примитива (`K.perimeter`) он различим всегда.

**Варианты** — решение Интегратора:
- (а) изменить G-2: «≤ 10⁻¹² — для колец по тождеству, d и примитива периметра; для колец общего вида — сертифицированная вилка, ширина печатается»;
- (б) поднять точность: интервальная арифметика повышенной точности для построения кольца. Это отдельная работа;
- (в) оставить G-2 как есть. Тогда расхождение регистрируется протоколом при приёмке.
