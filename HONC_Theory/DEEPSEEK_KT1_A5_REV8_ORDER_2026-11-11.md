## 3. Что мешает доказательству — по твоему коду rev7

**Н-1 — главное, из-за него не локализуется К4.** `gapTorusTorus` (`lib/geom.js`) строит нижнюю границу зазора выборкой по φ с поправкой Липшица L·h/2. При N = 360 и L = 1 это ≈ 0,0087. Ни один зазор меньше этой величины не получает знака.
- В К4 у ρ = 57,0° твоя вилка — [−0,0065; +0,0022], ширина как раз ≈ 0,0087.
- У `solveD` при N = 180 эта поправка вдвое больше.

**Н-2.** `solveD`: если знак в середине неопределён (`'0'`), бисекция сдвигает правый конец. Тогда вилка d (ширина ~10⁻⁶) не доказана — знаки на её концах не сертифицированы.

**Н-3 = B1.** sin / cos нестрогие:
- `I.sin` — `Math.sin` с запасом 10⁻¹²;
- `I.cos` сдвигает аргумент на `Math.PI/2`, ошибка сдвига не учтена;
- узлы φ в `gapTorusTorus` и точка кольца в `check2` берутся точечными `Math.cos` / `Math.sin`, без вилок.

**Н-4 = B2.** Проверка 1 работает в точках ρ. Единственность — «одна смена на сетке 0,25°», это не доказательство. Про ρ между узлами ничего не утверждается.

**Н-5 = B3.** Проверка 2 проверяет 51 точку ρ ∈ W, а не всю вилку W. Вилка d берётся из `solveD` с запасом ±0,01 (см. Н-2).

## 4. Что сдать

**Как доказывать — твоя зона.** Требования — ниже, без вариантов.

1. **Строгие вилки.** Каждая элементарная функция возвращает доказанную вилку: sin, cos, sqrt, ввод π и градусов. Довод — комментарием в коде и строкой в README. «Практический запас» не принимается.
2. **Зазор тор–тор с заданной точностью.** Нижняя граница строится так, чтобы ширина вилки зазора при необходимости уменьшалась до объявленной цели, например адаптивным делением по φ. Не хватило пределов деления — знак `?`, а не вердикт.
3. **Вилка d(ρ) доказана:** на её концах знаки зазора H1–T2 сертифицированы, для каждого ρ-ящика.
4. **Проверка 1 — на ящиках ρ.** Вилка [ρ_lo; ρ_hi] целиком покрыта ящиками.
   - Знак зазора H1–T1 сертифицирован на каждом ящике вне W.
   - Отсюда **все корни в вилке лежат в W** — это требуется.
   - Существование корня в W — по смене знака на сертифицированных соседних ящиках.
   - Единственность — если докажешь, отметь отдельно. Для вердикта она не обязательна: проверка 2 закрывает всю W.
5. **Проверка 2 — на всей W.** Для каждого ящика ρ из разбиения W доказано: на кольце 1→2 есть точка, у которой расстояние до средней окружности H1 меньше 0,5 (`dist_hi < 0,5`), при всех ρ ящика и всей вилке d(ρ). Точка (θ) может быть своей для каждого ящика.
6. **Вывод `run.js`:**
   - `existence: yes / no / undetermined`;
   - `all_roots_in_W: true / false`;
   - `uniqueness`, если доказана;
   - разбиение по ящикам со знаками;
   - итог проверки 2 по ящикам W;
   - итог `A5_VERDICT: FORBIDDEN / UNDETERMINED`;
   - объявленные параметры (цели ширины, пределы деления).
7. **README** (`a5/README.md`, новый):
   - что доказано и каким доводом;
   - объявленные параметры — до прогона, после результатов не менять;
   - что остаётся оговоркой.

**Форма:**
- файлы целиком, LF; только встроенные модули Node.js;
- сдаются изменённые и новые файлы;
- файл больше 12 КБ — по частям `### FILE: путь (часть N/M)`, байт в байт, по границе строки.
