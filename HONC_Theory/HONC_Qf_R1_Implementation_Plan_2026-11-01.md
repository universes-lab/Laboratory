### WP-1. Построение

- **Назначение.** Торы и кольца ЛМ1, звенья и навесы, свидетельства построения.
- **Входы.** WP-0. G-4 из WP-2 нужен только для незеркальных звеньев и для конфигураций, заданных границей касания.
- **Выходы** — конфигурация по ИФ-2:
  - торы (G-1);
  - кольца (G-2): пучок коник; периметр через полный эллиптический интеграл второго рода методом AGM; уравнение длины 2π решается вилкой; ширины вилок выдаются вместе с результатом *(поправка G-2, 02.11)*:
    - у кольца по тождеству — ≤ 10⁻¹²;
    - у кольца общего вида — сертифицированная вилка переменной ширины, ширина печатается;
  - расстояние звена (G-3): зеркальное — закрытая форма; незеркальное — корень G-4 с проверкой единственности;
  - параметризации (G-7): навес (ρ, ψ, δ) ↔ (α, λ, δ); звено хозяина (θ, φ, δ);
  - индикаторы планарности и кручения, определитель тройки (G-8, факультативно);
  - свидетельства построения:
    - параллельность пары из тождества (зеркальное звено с u ⊥ T даёт T_B = ±T_A) с наследованием по графу построения;
    - тип касания по построению;
    - `IMPOSED` с источником: сцепленная пара; граница первого касания (уравнение и вилка корня); симметрия переноса.
- **Требования.** G-1, G-2, G-3, G-7, G-8. Источник фактов для K-1, K-3, P-2, P-3.
- **Приёмка.**
  - А-1: при u = 0 кольцо — окружность радиуса 1, d = 2, допуск 10⁻¹².
  - Кλ1: d(u) по закрытой форме, допуск 10⁻¹².
  - Длина каждого построенного кольца: вилка содержит 2π *(поправка G-2, 02.11)*.
    - Ширина: у кольца по тождеству — ≤ 10⁻¹²; у кольца общего вида — печатается в протоколе, фиксированной границы нет.
    - Что истинная длина лежит в вилке, проверяется независимо (Э-Н) по полным вилкам полуосей из протокола, а не по их серединам.
  - Невязки построения — вилки содержат 0; ширина — по тому же правилу:
    - кольцо проходит через A и B;
    - касается T_A в A и T_B в B;
    - T_B лежит в плоскости кольца.
  - А-4 (G-7): две параметризации дают одну конфигурацию в пределах вилок.
  - А-2 (G-8): тройка = 1.
  - Зеркальный случай совпадает с прежним построением пучком коник (эталон Э-П).
  - Приближённой формулы периметра в ядре нет — ревизия кода.
  - Изменение параметра, нарушающее тождество параллельности, снимает `PARALLEL-ESTABLISHED`.
- **Обязан давать `UNRESOLVED`:**
  - единственность корня уравнения длины или G-3 не доказана;
  - перевод параметризаций в особой точке не определён;
  - построение при интервальном параметре не сходится.
- **Независимые проверки.**
  - Закрытые формы (А-1, Кλ1).
  - Длина кольца — независимое высокоточное интегрирование другим методом (Э-Н).
  - Невязки построения проверяются без знания алгоритма.
  - Инвариантность внутренних величин относительно жёстких движений.
  - Зеркальная пара ψ = 54°, δ = 10° и ψ = 306°, δ = −10° — зеркально-равные конфигурации (Э-М).
- **Не научный вывод.**

### WP-2. Сертифицированная статика тел (2D–2D и 1D–2D)

- **Назначение.** Непроникновение тор–тор и кольцо–тор.
- **Входы.** WP-0; WP-1. Какие торы кольцо продевает, известно по построению.
- **Выходы.**
  - G-4: вилка зазора тор–тор [g_lo, g_hi] и вилки всех точек минимума — точек или кривой. Это вход K-1.
  - G-5а: кольцо и непродетый тор — вилка запаса.
  - G-5б–г: кольцо и продетый тор — плоское сведение:
    - κ_r и запас 2 − κ_r в каспе (`EXACT`);

- **Требования.** § 2.11; § 2.10 — для сравнения; «прогон всех тестов обязателен до показа Автору».
- **Приёмка самого набора.**
  - Покрытие § 2.11 полное; это проверяет Интегратор.

- **Независимость.** Автор набора — не исполнитель ядра (ПР-6).
- **Не научный вывод.** Пройденная приёмка означает соответствие реализации контракту. Научных статусов она не меняет.

## 8. Протокол расхождения

**Поля:**
- случай и величина;
- прежнее значение, его метод и класс эталона;
- новое значение, вилка и полнота;
- разность;
- затронутые строки § 2.10 и испытания;
- предположение о причине, если есть, — с меткой [Г];
- статус `OPEN DISCREPANCY`.

**Маршрут:** исполнитель или автор испытаний фиксирует расхождение → отчёт КТ → физическая сторона — Клод, статусы — Хранитель → решение Интегратора.

**Разбор:**
- дефект реализации → исправление и регрессионное испытание;
- дефект эталона → исправление эталона с записью; допуск не меняется;
- дефект прежнего ядра (как м1, м2) → отмечается; значение Э-П заменяется только решением Интегратора;
- научный вопрос → по маршруту Б0; новых расчётов без разрешения нет.

**Запрещено:** менять допуски, параметры или эталоны, чтобы расхождение исчезло; выбирать параметры после просмотра результатов.

## 10. Вопрос к Интегратору и Хранителю (один, адресный)

**Тип касания для канонического чтения J5 (K-3, п. 2).** Это уточнение чтения, а не пересмотр контракта.
- Для параллельности v0.3 прямо запрещает канон по численному допуску.
- Для типа касания сказано: «боковое или торцевое по построению либо сертифицированно». Но вилка abs(n·T) может доказать только, что касание не чисто боковое или не чисто торцевое. Доказать точное равенство n·T = 0 или abs(n·T) = 1 она не может.
- Если же «сертифицированно» читать как попадание вилки в зону порога K-2, то источником канонического статуса становится порог, то есть численный допуск. Это тот же случай, который v0.3 исправил для параллельности.

**Чтение, которое WP-4 держит до ответа:**
- каноническим тип становится только по построению или аналитическому тождеству;
- численно можно установить лишь смешанный тип → `J5-EXT [Г, мост]`;
- всё остальное → `J5-CLASS-UNRESOLVED`;
- пороги K-2 нужны только для показа.

Базовые случаи не затронуты: в К1–К3, К5 и К6 тип задан построением, К4 идёт по расширению. Прошу подтвердить это чтение или указать другое. Если будет выбрана зона порога, значения порогов нужно объявить и принять как онтологический допуск — это решение Хранителя.
