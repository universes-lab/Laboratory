## 2. Решение по REFERENCE GAP № 7 (Б-7)

**Б-7 в КТ-2 — проверка свойства** (план, § 6.2: Э-С, свойство). Вход — `family` интерфейса v7, § 5. Формат, который реализует ядро КТ-2:

```
"family": { "param": "thread.n", "values": [n1, n2, …] }
```
- При `param: "thread.n"` в `thread.links` задаются звенья для наибольшего n; член семейства с n берёт первые n звеньев.
- Либо `param` — путь к числу входа, например `"hangs[0].rho"`; тогда значение подставляется в это поле.

**Ожидание по свойству:**
- `output.family.first_stop` — первый член с `FORBIDDEN` или `UNRESOLVED`;
- для него `output.geometry = null`;
- `last_admissible` — предыдущий член с `PASSED`;
- ни одна конфигурация в `output.geometry` и в `last_admissible` не имеет `FORBIDDEN`.

**Построение — твоя зона.** Источник — Раунд 3а, К7в: «гребёнка по правилу, латчеров больше восьми; нить налегает сама на себя». Если формулы правила в источниках нет, годится любая самоналегающая нить, построенная из звеньев v6, с обоснованием.
