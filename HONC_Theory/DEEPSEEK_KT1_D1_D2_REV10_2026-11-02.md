## м5(ii) — параллельность по допуску, подслучай (ii) — исправлено

**Класс:** Э-С. **Ловит:** м5. **Требование:** K-3; § 4.3 v6.

### Вход

```json
{"id": "m5ii",
 "tori": [
   {"name": "S1", "A": [0, 0, 0], "T": [0, 1, 0]},
   {"name": "S2", "A": [2, 0, 0], "T": [0, 1, 0.1]}
 ],
 "declare": [{"kind": "symmetry", "pair": ["S1", "S2"], "contact": "IMPOSED", "basis": "synthetic"}]}
```

**Что изменено:** ось S2 поворачивается вокруг **x̂** (линии центров), а не вокруг ẑ. Прежний вход `T: [0.1, 1, 0]` был поворотом вокруг ẑ — при этом торы расходятся, и `IMPOSED` противоречит рассчитанному зазору.

### Вывод (записывается в карточку)

**1. Ось после нормировки.** T_S2 = [0, 1, 0.1], |T_S2| = √1.01 ≈ 1.00499, нормировка даёт T̂_S2 ≈ [0, 0.99504, 0.09950]. Угол наклона к T_S1 = ŷ — θ ≈ 5,71°.

**2. Средняя окружность S2.** Центр (2, 0, 0), радиус 0.5, точки в координатах до поворота: (2 + 0.5 cos φ, 0, 0.5 sin φ). После поворота вокруг x̂ на θ: (2 + 0.5 cos φ, −0.5 sin φ sin θ, 0.5 sin φ cos θ).

**3. Точки на оси x̂ неподвижны.** При φ = π (точка в сторону S1) до поворота: (1.5, 0, 0); после: (1.5, 0, 0). Точка на оси x̂ не двигается поворотом вокруг неё.

**4. Средняя окружность S1.** Точка в сторону S2 при φ = 0: (0.5, 0, 0).

**5. Расстояние между ближайшими точками.** Кандидаты: S1(0.5, 0, 0), S2(1.5, 0, 0). Расстояние = 1.0.

Проверка минимума по ψ (S1) и φ (S2):
- при ψ = 0, φ = π: |(1.5, 0, 0) − (0.5, 0, 0)| = 1.0;
- при малых ψ: расстояние² ≈ 1 + 0.75 ψ² (см. ниже) — растёт;
- при ψ = π: S1(−0.5, 0, 0), минимум до S2 ≥ 1.5 — больше.

Расчёт производной для ψ = 0:
- расстояние² от (0.5, 0, 0) до S2(φ) = (1.5 + 0.5 cos φ)² + 0.25 sin²φ;
- производная по φ: −sin φ·(1.5 + 0.5 cos φ − 0.5 cos φ) = −1.5 sin φ;
- ноль при sin φ = 0; φ = π даёт 1.0 (min), φ = 0 даёт 4.0 (max на окружности).

При ψ = ε (S1 смещён с оси): S1 ≈ (0.5 − 0.25 ε², 0, 0.5 ε), S2(φ = π) = (1.5, 0, 0); расстояние² ≈ 1 + 0.75 ε² > 1. Значит ψ = 0 — локальный минимум по обоим параметрам.

**Вывод:** точка касания (1.0, 0, 0) сохраняется; расстояние между средними окружностями = 1.0; **зазор = 1.0 − 1 = 0** (трубки по 0.5). Объявленное `IMPOSED` согласовано с геометрией.

**6. Тип касания — SIDE у обоих торов.**
- Нормаль касания — x̂ (направление от (0.5, 0, 0) к (1.5, 0, 0));
- n · T_S1 = x̂ · ŷ = 0 → SIDE;
- n · T_S2 = x̂ · T̂_S2 = 0 → SIDE (ось S2 в плоскости yz, ⊥ x̂).

**7. Параллельность.** T_S1 × T_S2 = ŷ × T̂_S2 = [0, 1, 0] × [0, 0.99504, 0.09950] = [1·0.09950 − 0·0.99504, 0, 0] = [0.09950, 0, 0]. |T_S1 × T_S2| = 0.09950 ≫ ошибки вычисления (~10⁻¹⁵). `NON-PARALLEL`.

**8. Знак J5.** v_A = T_S1 × (c − A₁) = ŷ × x̂ = −ẑ. v_B = T̂_S2 × (c − A₂) = T̂_S2 × (−x̂) = [0, 0.99504, 0.09950] × [−1, 0, 0] = (0, −0.09950, 0.99504). v_A·v_B ≈ −0.995. **sign = −1.**

## Кλ3 — κ_r ≤ 2 для колец КТ-1 — исправлено

**Требование:** G-5в, G-5г; § 6.5 v6 (полная вилка).
**Зависит от параметра:** κ_min.
**Состояние:** ОЖИДАЕТ κ_min (усл.).

### Вход

Кольца из случаев **К1, К2(i), К2(ii), К2(iii), К3, К4**.

Спецификация § 2.10 задаёт для базовых случаев:
- К1, К2, К3: κ_r = 1 (кольцо по тождеству, u = 0);
- К4: κ_r = 1,366 (кольцо общего вида).

### Исключены из перечня

- **Кλ1.** Значение κ_r не выведено для θ = 85°.
- **А-5.** Спецификация не задаёт κ_r для колец А-5; кольцо R1 в этой конфигурации — прокол, а его κ_r не установлен спецификацией.

### Ожидаемое (на полной вилке кольца, без допуска)

Для каждого кольца из перечня вычисляется κ_r на **полной вилке** его полей (`C`, `E1`, `E2`, `s1`, `s2`) по § 6.5; запас κ = 2 − κ_r.

| Условие | Вердикт | Полнота | Примечание |
|---|---|---|---|
| κ_r < 2 **и** κ ≥ κ_min (на полной вилке) | **`PASSED`** | **`EXACT`** для К1–К3 (κ_r = 1 точно, ring by identity); **`CERTIFIED`** для К4 (κ_r = 1.366 с шириной из § 6.5) | Оба уровня полноты принимаются |
| κ_r < 2 **и** κ < κ_min (на полной вилке) | **`UNRESOLVED`** | — | Причина: κ < κ_min (спецификация TB-2; план § 3, WP-2, «Обязан давать UNRESOLVED») |
| κ_r = 2 | **`UNRESOLVED`** | — | Касание третьего порядка (G-5в) |
| κ_r > 2 | **`FORBIDDEN`** | — | G-5в |
| Вилка κ_r содержит 2 (нельзя установить знак κ_r − 2 или κ − κ_min) | **`UNRESOLVED`** | — | Причина: `ring-enclosure` с именем кольца и `width_max` |

**«При κ_min ≤ …»:** для К1–К3 порог κ_min должен быть ≤ 1 (иначе `UNRESOLVED`); для К4 — ≤ 0.63 (иначе `UNRESOLVED`). При прогоне с меньшим κ_min всё множество перечня даст `PASSED` с указанной полнотой.

### Что было исправлено (review 10)

1. **Вердикт и полнота разведены.** Прежде «κ ≥ κ_min → `CERTIFIED`» — это полнота, а не вердикт. Теперь: **вердикт `PASSED`**, **полнота `EXACT` или `CERTIFIED`** — принимаются обе. `EXACT` для К1–К3 (κ_r = 1 точно, ring by identity), `CERTIFIED` для К4 (κ_r = 1.366 с шириной).
2. **Добавлена ветвь κ < κ_min.** Спецификация TB-2 и план § 3 (WP-2 «Обязан давать UNRESOLVED») требуют: κ_r < 2, но κ < κ_min → `UNRESOLVED`.
3. **Остальные ветви без изменений.** κ_r = 2 → `UNRESOLVED`; κ_r > 2 → `FORBIDDEN`; вилка κ_r содержит 2 → `UNRESOLVED` с `ring-enclosure`.
4. **Причина исключения А-5 исправлена.** Не «там прокол, а не касп» (касп есть), а «спецификация не задаёт κ_r для колец А-5» — поэтому κ_r не выведен.

**Класс:** Э-А.

**Обоснование:** κ_r для эллипса в каспе (t = 0, конец полуоси s1) равна s1/s2². Порог κ_r = 2 = 1/0.5 — кривизна трубки тора.

**Ссылка:** спецификация, поправка 1, «Подтверждение Интегратора»: неравенство κ_r ≤ 2 проверяется на полной вилке кольца без допуска; равенство κ_r = 2 — не допуск; не устанавливается — `UNRESOLVED`.
