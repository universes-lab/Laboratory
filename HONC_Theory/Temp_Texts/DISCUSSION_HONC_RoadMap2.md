R_k / R₀ = (E₀ / E_вращ,k) • (Σ|Lᵢ| / |ΣLᵢ|)

5. Q0 — тёмная материя
Образ «пыль сквозь пальцы» [М] точно попадает в наблюдательный портрет тёмной материи. Она тяготеет и собирается в гало, но не сталкивается: проходит сквозь себя и сквозь вещество. В скоплении «Пуля» масса отстала от газа. Тёмная материя не охлаждается и не образует компактных структур.
Напряжение есть одно. Q0 у тебя — однородный фон, задающий диапазон «0 – c». Но однородный фон не тяготеет: в уравнение входит только избыток над I₀. А тёмная материя неоднородна, она в гало. ### HONC — Naming Synchronization
**Грамматика Q2-семейства:**

| Термин | Синхронизированное употребление |
|---|---|
| **Quantron / квантрон** | Элементарный объект Q1. Шесть вариантов Q1 соответствуют шести ароматам квантронов. Не использовать `quantron` для облачных структур верхних уровней. |
| **Latcher / латчер** | Элементарный объект Q2; динамический тип, способный двигаться и соединяться с другими латчерами. Основные варианты: **Qf** и **Qν**. |
| **Quantum Spiritus Sancti (QSS)** | Официальное собственное имя Q3. В строгом описательном контексте допустимо **transitional Q3 state / liminal Q3 state**. Русское «Квант Святого Духа» — буквальное авторское прочтение имени. |
| **Qu … Qb / Q_s1r1 … Q_t2r2** | Обозначения шести ароматов Q1-квантронов по комбинациям sphere/torus + ring относительно опорной оси. |

### 5. Вариант В1: сохранение I и L
**Начало:**
```
I₀ = (2/5)M₀R₀²
ω₀ = c/R₀
L₀ = (2/5)M₀R₀c
E₀ = (1/5)M₀c²
```
**Конец (оба обода на c):**
```
I_2D = (2/3)m_2D R²
I_ring = m_ring R²
ω_2D = c/R, ω_ring = c/R
```
**Сохранение I:**
```
(2/5)M₀R₀² = (2/3)m_2D R² + m_ring R²
```
**Сохранение L:**
```
(2/5)M₀R₀c = (2/3)m_2D Rc + m_ring Rc
```
Разделив второе на первое: **R = R₀**.  
Тогда оба уравнения дают одно и то же:
```
(2/5)M₀ = (2/3)m_2D + m_ring
```
С условием M₀ = m_2D + m_ring:
```
(2/5)(m_2D + m_ring) = (2/3)m_2D + m_ring
(-4/15)m_2D - (3/5)m_ring = 0
```
**Решения нет** (оба коэффициента отрицательны, массы положительны).  
**Статус:** В1 — **[С]**.

### 6. Вариант В2: сохранение L и E, остаток ΔE ≥ 0
**Сохранение L:**
```
(2/5)M₀R₀ = [(2/3)m_2D + m_ring]R
```
**Энергия вращения:**
```
E_вращ = (1/2)(2/3)m_2D R²(c/R)² + (1/2)m_ring R²(c/R)²
       = (1/3)m_2D c² + (1/2)m_ring c²
```
**Остаток:**
```
ΔE = (1/5)M₀c² − (1/3)m_2D c² − (1/2)m_ring c² ≥ 0
```
Обозначим μ = (2/3)m_2D + m_ring. Тогда:
```
R = (2/5)M₀R₀ / μ
ΔE/c² = (1/5)M₀ − (1/3)m_2D − (1/2)m_ring ≥ 0
```
Без условия M₀ = m_2D + m_ring система имеет две степени свободы (m_2D, m_ring). Требуется дополнительное условие.
**Кандидат:** условие, что остаток ΔE идёт в третью компоненту поля времени (статическую). Тогда ΔE — параметр, и для каждого ΔE есть решение. При ΔE = 0 получаем границу применимости.
При ΔE = 0:
```
(1/5)M₀ = (1/3)m_2D + (1/2)m_ring
```
С M₀ = m_2D + m_ring:
```
(1/5)(m_2D + m_ring) = (1/3)m_2D + (1/2)m_ring
(1/5 − 1/3)m_2D + (1/5 − 1/2)m_ring = 0
(-2/15)m_2D − (3/10)m_ring = 0
```
**Опять решения нет.** Значит, при ΔE = 0 система не замыкается с M₀ = m_2D + m_ring.
Нужно ослабить условие: M₀ ≠ m_2D + m_ring. Масса — коэффициент формы, она может перераспределяться. Тогда при заданном ΔE решение есть:
```
m_ring = [2(1/5)M₀ − 2(1/3)m_2D]
```
**Статус:** В2 — **[Г]** при условии перераспределения массы. Требует дальнейшего уточнения.
