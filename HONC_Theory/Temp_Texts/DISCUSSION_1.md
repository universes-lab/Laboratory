# 1. Current-state snapshot: what “current canon” actually is

The repository is **not a completed theory canon**. It is an unfinished knowledge-library build containing:

- library/architecture specifications;
- draft axioms;
- a number of definitions already marked `canon`;
- several `canon-provisional` TD definitions;
- source editions/books;
- a largely unpopulated formalism/dynamics structure.

This matters because PASS 2 must not treat “exists in repository” as “final theory.”

## 1.1 Three draft axioms

Current repository state contains:

- **OBJ-001 — Space is discrete** — `draft`.
- **OBJ-002 — Time is a multi-component field** — `draft`.

# 2. dt/dx ontological core used in this comparison

No attempt is made here to validate the old Temporal Dynamics formulas.

The minimal dt/dx core supported by the current repository plus the discussion is:

1. Time is represented as a **multi-component field** \(T_{\mu\nu}\), not merely an external scalar parameter.
2. The field is defined on a **discrete spatial substrate/lattice**.
3. The physical description is to be reformulated from the ordinary emphasis on \(dx/dt\) toward **\(dt/dx\)**.
4. In the discussion this is sharpened as **slowness**, not merely “inverse velocity notation.”
5. “Motion” in HONC 2.0 tends toward **propagation/reassignment of a temporal-field state/pattern over stationary spatial quanta**, not transport of an elementary material bead.
6. Force, energy and mass are intended to be **derived/classical-limit quantities**, not primitive ontology.
7. The common linear/inertial temporal component is treated late in the protocol as the **shared carrier / internal ruler** for all quanta of our space.
8. \(c\) is reinterpreted in the native dt/dx language as a **slowness boundary** rather than only as “maximum velocity.”

Everything beyond this — explicit equations for reactivity, inertiality, \(\hbar_{\rm TD}\), dispersion, conserved quantities, etc. — remains subject to mathematical rederivation.
