## Дополнение — перенос кольца без проникновения: лемма об описанной сфере

В OPEN стоит: «U vs S для Qs↔Qc; перенос кольца без проникновения — чужая статика / permit». Его закрывает короткая выкладка без всякого счёта ядром.

**Посылки** — геометрия носителей, принятая в КТ: рог-тор R = r = ½; кольцо — окружность длины 2π, то есть радиуса 1; у Q1 общий центр (соцентрический режим). Применимость этих размеров к Q1 опирается на «один масштаб у всех ароматов» (Автор, 26.10). Это условие надо подтвердить.

**Утверждение.** Кольцо радиуса 1 с общим центром при **любой** ориентации лежит на единичной сфере, описанной около рог-тора, и тора не проникает.

**Вывод.** Для точки кольца |p| = 1, то есть ρ² + z² = 1, где ρ — расстояние до оси тора. Условие «снаружи тора»:

(ρ − ½)² + z² − ¼ = ρ² + z² − ρ = **1 − ρ ≥ 0**.

Равенство — только при ρ = 1, z = 0, то есть на внешнем экваторе тора.

**Касание** — пересечение кольца с внешним экватором:
- **вся окружность**, если плоскость кольца совпадает с экваториальной плоскостью тора;
- **ровно две противоположные точки** при любой другой ориентации.

Проверено численно на 20 000 случайных ориентаций: минимум левой части — 3·10⁻¹⁶; у наклонных колец не больше двух точек касания.

**Следствия:**
1. **Перенос кольца не препятствие.** Поворот кольца вокруг общего центра никогда не даёт проникновения: кольцо катится по описанной сфере. Это не «чужая статика» КТ и permit не требует.
2. **Классы жёстких тел — это классы касания:**
   - тор + кольцо на внешнем экваторе (Qs) — касание по всей окружности;
   - тор + кольцо в меридиональной плоскости (Qc, Qt, Qb) — касание в двух точках;
   - сфера + кольцо (Qd, Qu) — если радиус сферы равен 1, кольцо лежит на ней при любой ориентации и касается по всей окружности. Размер сферы в корпусе надо подтвердить.
3. **Асимметрия Qs↔Qc получает геометрический смысл.** Это единственная пара, где переворот меняет класс касания: окружность → две точки. У Qd↔Qu касание остаётся окружностью, у Qb↔Qt — двумя точками. «То же 2D-тело» операционально — тот же носитель, а класс касания при этом может меняться.

**Статус:** [Д-Кл], Клод_А, при посылках КТ о носителях. Нужно воспроизведение вторым участником. Выкладка касается одиночного Q1 — не λ-сборок и не карточек КТ-2.
