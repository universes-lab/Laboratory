## 2. Координаты, обозначения, допуски — обязательны

- R = 1. Центр всех тел — начало координат O, если не сказано иное.
- Ось z — вертикаль (П5). e_x, e_y, e_z — орты.
- **Тор T(k)**: единичный вектор оси k; радиус осевой окружности ½; радиус трубки ½. Для точки p: h = p·k, ρ = |p − h·k|, **F(p) = (ρ − ½)² + h² − ¼**. Точка внутри тора ⇔ F(p) < 0.
- **Осевая окружность тора**: центр O, радиус ½, в плоскости, перпендикулярной k.
- **Сфера S**: центр O, радиус 1; **G(p) = |p| − 1**.
- **Кольцо K(n, c, r)**: окружность радиуса r, центр c, единичная нормаль n. По умолчанию c = 0, r = 1. Обозначение K(n) — при c = 0, r = 1.
- **Классы кольца относительно тора** (по точкам кольца):
  - «проникновение» — есть точка с F < −10⁻⁹;
  - «касание» — нет проникновения, есть точка с F ≤ 10⁻⁶;
  - «свободно» — min F > 10⁻⁶.
- **Классы кольца относительно сферы:**
  - «на оболочке» — |G| ≤ 10⁻⁹ во всех точках;
  - «пересекает оболочку» — min G < −10⁻⁹ и max G > 10⁻⁹;
  - «касание» — не «на оболочке», не «пересекает», и min |G| ≤ 10⁻⁶;
  - «внутри» — max G < −10⁻⁶; «снаружи» — min G > 10⁻⁶.
- **Число точек касания при переборе точек**: число строгих локальных минимумов F вдоль кольца (последовательность точек замкнута в цикл), в которых F ≤ 10⁻⁶. Если F ≤ 10⁻⁶ во всех точках кольца — пиши «окружность».
- Точки на кольце — равномерно по углу, начиная с угла 0, если не сказано иное.

## Часть A. Лемма об описанной сфере

**A1. Сверка размеров и центра.** Таблица из пяти строк: внешний радиус тора (a + b); радиус кольца; радиус сферы; центр тора; центр кольца. В каждой строке — значение, которое ты берёшь в счёт, и номер посылки (П1–П3), из которой оно следует. Одной строкой под таблицей: равны ли три радиуса.

**A2. Утверждение У-1. Докажи сам, аналитически.**

> Для любой единичной нормали n кольцо K(n) не проникает в тор T(e_z). Точки касания: вся окружность, если n = ±e_z; ровно две противоположные точки при любой другой n.

Запиши вывод полностью. Найди точки касания явно, как функцию n. Если У-1 неверно — приведи контрпример и остановись на этом пункте; остальные пункты выполняй.

**A3. Утверждение У-2. Докажи.**

> Для любой единичной нормали n кольцо K(n) лежит на сфере S.

**A4. Численная проверка У-1.**
- Нормали: 100 000 векторов; три координаты — `rng.normal(size=(100000, 3))`, затем каждый вектор нормируется; `rng = numpy.random.default_rng(20261116)`.
- На каждом кольце — 3 600 точек.
- Вывести:
  1. минимум F по всем точкам всех колец;
  2. число колец с проникновением;
  3. для колец с |n_z| < 1 − 10⁻⁶ — распределение числа точек касания (сколько колец имеют 0, 1, 2, 3 и более);
  4. для n = e_z — класс и число точек касания.

**A5. Чувствительность к размерам и центру.**

(а) **Радиус кольца.** r ∈ {0,90; 0,99; 1,00; 1,01; 1,10}, центр O. Нормали: 2 000 векторов тем же способом и тем же `rng` (второй вызов после A4), плюс n = e_z и n = e_x. Для каждого r: min F по всем нормалям; класс относительно тора T(e_z) (худший по нормалям: проникновение > касание > свободно); класс относительно сферы S для n = e_z.

(б) **Смещение центра кольца относительно тора T(e_z).** c = d·e.
- n ∈ {e_z — экваториальное; e_y — меридиональное, кольцо в плоскости xz; e_x — меридиональное, кольцо в плоскости yz};

- d ∈ {0; 0,25; 0,5; 0,75; 0,99; 1,00; 1,01; 1,5; 1,99; 2,00; 2,5};
- 3 600 точек на кольце.

Всего 99 строк. Столбцы: n, e, d, min F, класс, число точек касания и их координаты (для «касания»), **L** — число зацепления кольца с осевой окружностью тора. L считай интегралом Гаусса (2 000 × 2 000 точек); приведи неокруглённое значение и округлённое до целого. **L считай только в строках без проникновения**; в строках с проникновением пиши «—».

(в) **Смещение центра кольца относительно сферы S.** n ∈ {e_z, e_x}; e ∈ {e_x, e_z}; d — тот же список. Всего 44 строки. Столбцы: n, e, d, min G, max G, класс.

## Часть B. Реестр положений одиночного Q1 (центр общий)

**B1. Наклон кольца у тора.** Тор T(e_z), кольцо K(n), n = (sin θ, 0, cos θ), θ ∈ {0°, 1°, 5°, 15°, 30°, 45°, 60°, 75°, 85°, 89°, 90°}.

Для каждого θ:
1. min F (3 600 точек);
2. точки касания — аналитически, из A2: «окружность» или координаты двух точек;
3. **группа симметрии пары (тор, кольцо)**, способ — ниже.

**Способ поиска группы симметрии — обязателен.**
- Проверь все 48 матриц со знаковыми перестановками: 3 × 3, в каждой строке и каждом столбце ровно одна ненулевая ячейка, равная +1 или −1.
- Матрица M — симметрия тора T(k), если M·k = ±k. Симметрия сферы — любая M. Симметрия кольца K(n), центр O, — если M·n = ±n. Симметрия прямой V — если M·V = ±V.
- Отдельно проверь **непрерывную симметрию**: поворот на 10° вокруг оси тора (для сферы — вокруг n) — симметрия пары, если переводит каждый объект в себя по тем же условиям.
- Запиши: число найденных матриц из 48; список этих матриц (строками); есть ли непрерывная симметрия (да/нет).

**B2. Сфера.** Сфера S, кольцо K(e_z). Группа симметрии пары — тем же способом.

**B3. Кандидаты «класс положения + вертикаль».** Вертикаль V — ось вращения квантрона целиком (П5). Перебери десять кандидатов:

| Класс положения | 2D-тело | Нормаль кольца n | V |
|---|---|---|---|
| С | сфера S | e_z | e_z; e_x |
| Э (экваториальное) | тор T(e_z) | e_z | e_z; e_x |
| М (меридиональное) | тор T(e_z) | e_x | e_z; e_x; e_y |
| Н (наклонное, 45°) | тор T(e_z) | (sin 45°, 0, cos 45°) | e_z; n; e_y |

Для каждого кандидата:
1. **Метка тела:** «вдоль», если V = ±k; «поперёк», если V·k = 0; иначе «наклон». Для сферы — «сфера».
2. **Метка кольца:** «вдоль», если V = ±n; «поперёк», если V·n = 0; иначе «наклон».
3. **Группа симметрии тройки** (тело, кольцо, прямая V) — способом B1. Непрерывную симметрию проверяй поворотом на 10° вокруг V.
4. **Совпадение с П5 и П6.** Пиши имя квантрона, если обе метки совпадают со столбцами «2D-тело» и «Кольцо» его строки в П5 **и** класс положения совпадает с П6. Если метки совпадают со строкой, а класс положения нет — пиши «метки как у Q…, класс положения другой». Если меток такой строки нет — «нет».

**B4. Изменения положения без проникновения.**

(а) **Поворот кольца вокруг общего центра.** Нормаль n(t) идёт по дуге большого круга от n₁ к n₂; 200 шагов; 3 600 точек на кольце.

| Путь | Тело | n₁ → n₂ |
|---|---|---|
| Э → М | тор T(e_z) | e_z → e_x |
| М → М | тор T(e_z) | e_x → e_y |
| С → С | сфера S | e_z → e_x |

Для каждого пути: min F (для сферы — min G и max G) по всему пути; на каких шагах точки касания — «окружность», на каких — две точки, на каких — иное.

(б) **Смещение центра.** По таблице A5(б) выпиши для каждой пары (n, e) значения d из списка, при которых нет проникновения.

(в) **Смена вертикали при неподвижных телах.** Для трёх кандидатов класса М (B3) сравни взаимное положение тора и кольца, то есть векторы k и n. Запиши одной строкой: одинаково или различно.

## Часть C. Направления скоростей в точках касания — только числа

**Модель.** Вращение части вокруг оси u, проходящей через O, с единичной угловой скоростью и знаком «+» даёт в точке p скорость **v = u × p**. Вертикаль — e_z.

| Строка | Тело и ось k | Нормаль кольца n | Вращения 2D-тела (оси u) | Вращения кольца (оси u) |
|---|---|---|---|---|
| Qd | сфера | e_z | собственное e_z | собственное e_z |
| Qu | сфера | e_x | собственное e_z | собственное e_x; меридиональное e_z |
| Qs | тор, k = e_z | e_z | собственное e_z | собственное e_z |
| Qc | тор, k = e_z | e_x | собственное e_z | собственное e_x; меридиональное e_z |
| Qt | тор, k = e_x | e_z | собственное e_x; меридиональное e_z | собственное e_z |
| Qb-A | тор, k = e_x | e_y | собственное e_x; меридиональное e_z | вокруг диаметра e_x; меридиональное e_z |
| Qb-B | тор, k = e_x | e_y | собственное e_x; меридиональное e_z | собственное e_y; вокруг диаметра e_x |
| Э-x | тор, k = e_x | e_x | собственное e_x; меридиональное e_z | собственное e_x; меридиональное e_z |

Пояснения к модели:
- «Меридиональное» здесь — вращение части вокруг вертикали e_z, когда ось части не вертикальна.
- Две строки Qb — два прочтения фразы Свода (§ 3.5, п. 6): «кольцо Qb … вращается вокруг своего диаметра, параллельного оси тора». Прочтение A: это вращение заменяет собственное вращение кольца. Прочтение B: собственное вращение сохраняется, а вращение вокруг диаметра — меридиональное. Считай обе строки.
- Э-x — кандидат класса Э с V = e_x из B3, записанный в координатах, где вертикаль — e_z. Это не квантрон из П5; считай для сравнения.

**Точки касания:**
- если касание — окружность, бери 8 точек: для n = e_z — p_j = (cos(45°·j), sin(45°·j), 0); для n = e_x — p_j = (0, cos(45°·j), sin(45°·j)); j = 0…7;
- если касание — две точки, бери обе точки, найденные по A2. Ось тора здесь может быть e_x: находи точки той же формулой в повёрнутых координатах.

**Что вывести.** Для каждой строки, каждой точки касания и каждой пары (вращение 2D-тела, вращение кольца) — косинус угла между v₂D и v₁D. Если |v₂D| < 10⁻¹² или |v₁D| < 10⁻¹², пиши «0».

**Сводка по строке:** для каждой пары вращений одно слово:
- «коллинеарны» — косинус +1 или −1 во всех точках, где обе скорости ненулевые;
- «ортогональны» — косинус 0 во всех таких точках;
- «прочие» — иначе.
