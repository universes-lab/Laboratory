## 1. Термины — по решению Автора

| Термин | Смысл |
|---|---|
| **quay / причал** | архитектура целиком, определяемая отношениями причаливания латчеров или латчерных цепей |
| **latchplex** | класс связных Q2-структур |
| **latchform** | морфология latchplex |
| **mooring site** | локальное место причаливания |
| **λ-molecule** | только историческое обозначение исследованных замкнутых Qf-сборок. Старые файлы не переименовываются; прямой замены «λ-molecule → quay» нет |

**Предупреждение в шапке каждой публичной страницы — дословно, RU и EN:**

> Пять quay HONC представляют разные архитектурные классы, объединённые принципом причаливания, а не единый доказанный физический класс. Их названия не означают установленного тождества с частицами Стандартной модели.

## 2. Три слоя статуса — у каждого свой

| Слой | К чему относится | Значения |
|---|---|---|
| статус элемента | отдельный носитель: тор, сфера, кольцо — его геометрия | [К], [Д], [Д-Кл], [Г], [О] |
| статус сборки | архитектура целиком | [К], [Д], [Д-Кл], [Г], [О], «ранняя модель», HOLD |
| статус перехода | движение или смена состояния | см. § 3 |

**Правило:** статус сборки **не выводится** из статусов элементов. Проверенный тор в гипотетической сборке остаётся проверенным тором; сборка остаётся гипотетической.

**[мост]** — отдельная пометка для привязок к внешней физике.

Как показывать статусы, решает разработчик. Обязательно одно: три слоя различимы на экране, и есть действие, которое убирает со сцены всё, кроме [К] и [Д].

## 3. Классы движения

| Класс | Что это | Обязательно |
|---|---|---|
| **Т1** | канонически определённое вращение внутри известного состояния: собственные и меридиональные вращения частей по таблице типов | плавно. Плавность — изобразительная: закон смены кадров не утверждается |
| **Т2** | геометрически допустимая последовательность положений; закон перехода не установлен. Сюда относится **любое произвольное изменение наклона кольца квантрона** | только как цепочка проверенных положений, с подписью «геометрия, не превращение» |
| **Т3** | разрыв: непрерывного допустимого пути нет | **никакого морфинга;** промежуточное состояние, в том числе Q0*, не изображается как установленное; подпись «маршрут [О]» |
| **Т4** | исследуемый режим [Г] | только по включению зрителем, с постоянной пометкой [Г] |

**Запрещённое состояние не рисуется никогда.** Показ запрета — неподвижные «призраки» или показ запрещённой области, без анимации входа в неё.

## 4. Числа и таблицы

- Число конфигураций из таблиц канона (например, 16 знаковых конфигураций пары) — это **таблица знаков**, а не число динамических режимов сборки. Так и подписывается.
- **Линза осей и знаков** — данные о структуре: оси вращения элементов и их знаки. Полем времени она не называется.
- Мостовые величины (например, гироскопический момент) — отдельным слоем, с пометкой [мост].
- **Объёмное поле времени не изображается**, пока нет закона поля и отдельного решения Интегратора и Автора. Место для этого слоя в данных предусмотрено.

## 5. Описание сцены — данные

Каждый quay — это файл данных JSON и модуль сцены.

```json
{
  "quay_id": "Z-type-closed",
  "assembly_status": "early-model",
  "elements":    [{"id": "T0", "kind": "horn-torus", "pose": {"c": [0,0,0], "axis": [0,0,1]}, "element_status": "К", "source": "SRC-…"}],
  "transitions": [{"id": "tr1", "class": "T1", "of": ["T0"], "axis": "own", "transition_status": "К", "source": "SRC-…"}],
  "lenses":      {"axes_signs": {"source": "SRC-…"}, "bridge": null, "field": null},
  "i18n":        {"ru": "…", "en": "…"},
  "viewpoints":  [{"id": "v1", "pos": [0,0,8], "target": [0,0,0]}]
}
```

- `source` — идентификатор в общем **реестре источников**: файл, раздел, сумма, статус, а также разрешение для публичной сборки — по положительному списку Грока.
- Числа берутся только из источников реестра. Свои вычисления разработчика допускаются только для построения формы по формулам из источника, и каждая формула указывается.
- **Новых физических расчётов сцены не вводят.**

## 6. Сторож геометрии — двухступенчатый

1. **Заранее:** каждая неподвижная конфигурация сцены проверяется на непроникновение носителей с запасом. Используется общий модуль `core/`: чистые функции, без графики.
2. **В браузере:** разрешены только движения с доказанным инвариантом:
   - вращение носителя вокруг собственной оси симметрии;
   - вращение структуры как целого;
   - поворот кольца квантрона вокруг общего центра — лемма Q1-01;
   - переключение между проверенными конфигурациями.

   Другое движение — только с заранее доказанной границей на весь интервал и с записью в реестр.

Сторож не зависит от материалов, камеры и эффектов.

**Сторож проверяет геометрию, а не закон.**
- Геометрический инвариант (например, лемма Q1-01 для любого наклона кольца) разрешает показать положение, но не делает смену положений движением Т1.
- Самоповорот симметричного носителя — изобразительная анимация канонического вращения, а не доказанная физическая эволюция.
- Для сборок со статусом «ранняя модель» результат сторожа — технический контроль, а не научный PASS; на странице он показывается только в лабораторной сборке.
- Если найдено проникновение, конфигурация **блокируется**, а показ останавливается. Маскировать проникновение светом, прозрачностью или ракурсом нельзя.
