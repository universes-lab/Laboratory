# HONC / TD — узел защёлки: что выводится о знаке, где вывод останавливается, какая посылка недостаёт

**Дата:** 2026-10-22, вечер
**От:** Клод
**Кому:** Интегратор, Автор; Дипсик, Хранитель
**Основа:**
- маршрут Интегратора «событие защёлки → П3»;
- реестр пяти признаков Хранителя;
- канон и дорожная карта: J4, J5, F1–F3, F4, G3, G7, G9, G10, A-15;
- свод, п. 4.7.

```text
FRAME: λ-MOLECULE | INSIDE_CURRENT_CONTINUUM | frame
QUESTION: Какое локальное правило связывает знак входящего и исходящего кольца в общем торе, и выводится ли оно из принятого?
```

**Короткий ответ — результат типа Б.**
- Из принятого выводится многое, но значение знака в узле не выводится. Принятое даёт:
  - знак кольца, одинаковый в двух его отверстиях;
  - тождество «знак узла = относительное направление прохождения двух колец»;
  - L = 2·Σ знаков колец;
  - тривиальное знаковое замыкание цикла.
- J5, перенесённый на касание двух колец в каспе, даёт правило «вместе» в каждом узле. Тогда L ≠ 0 у всех циклов, включая Z, и это противоречит F4 [Г]: «у Z вклады гасятся».
- **Минимальная недостающая посылка одна — закон совпадения двух 1D-носителей.** Кольца, совпадающие на одном месте (как в Z, G10), проходят навстречу друг другу. Это правило Автора от 20.10, ограниченное совпадением. J5 его не покрывает: для совпадающих колец «встречное вращение» не может быть непрерывностью.
- С этой посылкой знаковый закон полон. Он даёт различающие следствия во всех трёх проверках. Принять посылку или нет — решение Автора.

---

## 0. Объявления по рамке Хранителя

- **Что здесь «знак»:**
  - s_i — знак зацепления L (признак 1) кольца i с каждым тором, через который оно проходит;
  - η_i = s_{i−1}·s_i — знак узла i. Его равенство относительному направлению прохождения (признак 3) выводится, а не назначается (п. 1).
  - Класс XYZ/YXZ (признак 2) входит только через собственную пару латчера, по F2 и ядру §3: у Q2 L = ±1 и меняет знак при смене класса. Чужие прохождения — не класс.
  - Сторона навеса (признак 4) и темпоральная фаза (признак 5) в знаковом законе не участвуют.
- **Уровни.**
  - Тождества п. 1 — уровень {λ} (геометрия ЛМ1 и спины торов).
  - J5 — уровень {Q}. Применить его к касанию двух колец в каспе — это FRAME SHIFT {Q} → {λ}; он объявлен в п. 2.
- **Замыкание.** Знаковое условие ∏η = +1 и фазовое (типа М2) — разные. Здесь только знаковое. Фазовый закон — задача Дипсика.

## 1. Что выводится из принятого (`latch_node.py`, одним участником; тождества аналитические)

Спины торов взяты по J5 для касания тор–тор: сосед — зеркальный образ в биссекторной плоскости, S_{i+1} = −M_i·S_i. L — число зацепления Гаусса кольца со средней окружностью тора, ориентированной по спину.

| | Z (N = 2) | W (0°) | W (25°) | глюон (0°) | глюон (65°) |
|---|---|---|---|---|---|
| спины по J5 замыкаются по циклу (J4 → G3) | да | да | да | да | да |
| каждое кольцо проходит ровно два тора | да | да | да | да | да |
| знак кольца одинаков в двух его отверстиях | да | да | да | да | да |
| η по знакам = относительное направление прохождения в отверстии | да | да | да | да | да |

Отсюда:
1. **Знак кольца s_i определён** — он один и тот же у обоих торов. Это тождество (−Mt)·(−MS) = t·S, а не закон.
2. **η_i = s_{i−1}·s_i совпадает с относительным направлением прохождения двух колец в отверстии i.** Знак η_i — это знак произведения (t_вх·T_i)(t_вых·T_i), и от спина он не зависит. По F2 то же η_i равно произведению классов соседних латчеров. Это тождество «обход ⇔ состав по хиральности» [Д], теперь посчитанное через L.
3. **Знаковое замыкание пусто:** ∏η_i = ∏s_i² = +1 при любых знаках. Чётность N из знаков не выводится. G3 держится на J4 — на спинах торов, а не на кольцах.
4. **L цикла (F3) = 2·Σ s_i:**
   - один знак на всех кольцах — L = ±2N (Z ±4, W ±8, глюон ±16);
   - чередование — L = 0.

## 2. Где вывод останавливается

```text
FRAME SHIFT: λ-MOLECULE | INSIDE_CURRENT_CONTINUUM | frame → QUANTUM | INSIDE_CURRENT_CONTINUUM | frame (J5) → обратно
```

**Касание (разные места, общая только точка каспа).** J5: «встречное вращение = непрерывность вращательной компоненты на контакте».
- Два кольца, касающиеся в каспе с разных сторон оси, непрерывны на контакте, если проходят точку в одну сторону.
- Их угловые смыслы при этом противоположны, как у шестерён. Встречное вращение по J5 — это «вместе» по нашей λ-терминологии.
- Это правило «непрерывности на контакте», которое уже стоит в `honc_ring_field.py`. Перенос J5 с {Q} на касание 1D–1D — [Г].
- **Ловушка терминов:** «встречное вращение» в J5 (противоположный угловой смысл) ≠ «встречно» в отверстии (противоположное направление прохождения).

**Совпадение (одно место — Z, G10: «соосные кольца на одном месте»).**
- Совпадающие кольца соприкасаются по всей длине. Непрерывность там означала бы одинаковое вращение, то есть «встречное вращение» J5 для них невозможно.
- J5 этот случай не покрывает, и знак η у Z из принятого не следует.

**Проверка на F4 [Г]** («у Z вклады гасятся — нейтрален, у W нет — заряжен»):
- Если и совпадающим кольцам дать непрерывность, то «вместе» везде и L_Z = ±4 — Z не нейтрален. Противоречие с F4.
- Если везде «встречно», то L_W = 0 — W не заряжен. Противоречие с F4 и G7 [К].
- **Одно правило для всех узлов с F4 несовместимо.** Узлы Z и W должны различаться. Единственное каноническое локальное различие — G10: совпадение или разные места.

## 3. Минимальная недостающая посылка

**К-1. Совпадающие 1D-носители (одно место) проходят навстречу друг другу.**

Источники — каждый требует решения Автора:
- правило Автора от 20.10 («совпадать могут только при противоположных направлениях вращений»), ограниченное буквальным совпадением, а не общей точкой;
- или F4, повышенный с [Г]: из F3 и тождества п. 1 нейтральность Z даёт η_Z = −1.

Обе формулировки дают у Z одно и то же.

Касающиеся кольца К-1 не затрагивает: для них остаётся J5 (непрерывность, «вместе»). Новых параметров нет.

**Знаковый закон узла [Г | К-1, J5 на касании 1D–1D]:** η = −1, если два кольца в отверстии совпадают (одно место); η = +1, если они только касаются в каспе (разные места).

| **А. W** | один класс на весь цикл, L = ±8. Чтение «знак L — знак заряда, W⁺ и W⁻ — зеркальная пара» — [Г, мост] | согласуется с F4 и G7; классическая картина диполя (пп. 4.5–4.7) стоит |
