## 1. Какие положения одиночного Q1 геометрически допустимы

| Что | Результат | Статус |
|---|---|---|
| Наклон кольца у тора, θ от 0° до 90° | допустим **любой**; касание — вся окружность при θ = 0°, две точки при любом θ > 0° | [Д] |
| Симметрия пары «тор + кольцо» | θ = 0°: непрерывная (порядок 16 среди проверенных + вращения); 0° < θ < 90°: порядок **4**; θ = 90°: порядок **8** | [Д] |
| Сфера + кольцо | любой наклон, кольцо всегда на оболочке | [Д] |
| Радиус кольца | касание без проникновения — **только при r = R**: 0,99R — проникновение, 1,01R — касания нет | [Д] |

**Следствие.** Шесть ароматов стоят только в двух концах интервала наклона (0° и 90°), где симметрия наибольшая. Внутренние наклоны геометрически допустимы, но ароматами не являются. Общий внешний радиус R — условие касательной конфигурации, а не оформление.

## 2. Какие изменения положения возможны без проникновения

**Поворот кольца вокруг общего центра — всегда** (экваториальное ↔ меридиональное, меридиональное ↔ меридиональное, на сфере) — [Д].

**Смена оси вращения квантрона при неподвижных телах.** У Qc, Qt, Qb взаимное положение тора и кольца одно и то же. Это **одна жёсткая фигура**; три аромата — три выбора оси вращения квантрона среди трёх её осей симметрии: ось тора → Qc, нормаль кольца → Qt, третья ось → Qb — [Д].

**Смещение центров** — выход из соцентрического режима. Тор с осью e_z; d — сдвиг центра кольца в единицах R:

| Кольцо и направление сдвига | Допустимые d | L | Статус |
|---|---|---|---|
| меридиональное, в своей плоскости поперёк оси тора | только **0**, **1** и **≥ 2** | 0; **±1**; 0 | [Д] |
| меридиональное, вдоль оси тора | 0 и d ≥ 1,5 (между 1,01 и 1,5 — граница) | 0 | [Д] |
| меридиональное, перпендикулярно своей плоскости | любое; касание пропадает сразу | 0 | [Д] |
| экваториальное, в своей плоскости | только 0 и ≥ 2 | 0 | [Д] |
| экваториальное, вдоль оси тора | любое; касание пропадает сразу | 0 | [Д] |

При d = 1 в первой строке кольцо проходит через касп тора, L = ±1: это геометрия латчера ЛМ6. **Квантрон (d = 0) и латчер (d = R) — два изолированных допустимых положения; любой промежуточный сдвиг проникает в тор.** У экваториального кольца латчерного положения нет вовсе.

## 3. Какие ограничения ещё нужны для утверждения о реальном переходе

**3.1. Закон времени.** Статически проходимый путь — не переход (§ II.5). Нужен закон: за сколько кадров и как меняется ориентация кольца или ось вращения. Его нет.

**3.2. Q1 ↔ Q2 — нового закона не нужно.** Непрерывного пути без проникновения нет: допустимы только d = 0 и d = R, а L меняется с 0 на ±1. Это согласуется с действующим «L сохраняется при сдвигах, не рвущих носители; на Q0* L не определён». Значит, переход квантрон ↔ латчер идёт только через Q0* или с разрывом носителя — [Д] при каноне. Недостаёт лишь правила самого перехода через Q0*.

**3.3. Направления вращения в точке касания (часть C).** В каждом аромате есть **ровно одна пара** «вращение 2D-тела — вращение кольца», скорости которой в точках касания коллинеарны:

| Ароматы | Коллинеарная пара | Собственные вращения тела и кольца в точке касания |
|---|---|---|
| Qd, Qs | собственное тела — собственное кольца (общая ось) | коллинеарны |
| Qb (оба прочтения) | собственное тора — вращение кольца вокруг диаметра, параллельного оси тора | — |
| Qu, Qc | собственное тела — меридиональное кольца | ортогональны |
| Qt | меридиональное тора — собственное кольца | ортогональны |

**Наблюдение [Г].** Метку ∥/⊥ можно прочесть как способ, которым образуется согласованная пара:
- ∥ — из собственных вращений частей;
- ⊥ — только с участием вращения квантрона целиком (меридионального).

Тогда столбец «меридиональное вращение» у Qu, Qc, Qt — это ровно то вращение, без которого согласованной пары нет. Qd и Qs его не имеют, и оно им не нужно. Меридиональные вращения Qb так не объясняются: его пара образована без них.

**Чего недостаёт, чтобы это стало законом:** правила J5 для контакта «кольцо — поверхность 2D-тела». Сейчас J5 сформулирован для касаний 2D-носителей, скольжение кольца по поверхности разрешено, равенство скоростей не выведено. Кандидат закона: «в точке касания кольца с 2D-телом есть пара вращений с согласованным направлением» — [Г], на решение Автора после разбора.

Таблица C не различает два прочтения Qb: обе строки дают одну и ту же коллинеарную пару. Развилка Qb (кадровое переотображение или физическое вращение) остаётся открытой.

**3.4. Наклонные положения.** У наклонного кольца скорости собственных вращений в точке касания идут под углом θ — ни коллинеарны, ни ортогональны. В каноне точная форма J5 для непараллельных осей — [О]. Именно этот пробел решает судьбу наклонных положений: либо они только переходные, либо нужен закон отбора. Кандидат: устойчивы лишь положения наибольшей симметрии — [Г].

## 4. Следствия для классификации шести ароматов

**4.1. Шесть из семи.** Перебор «класс положения × ось вращения квантрона среди осей симметрии» даёт **семь** симметричных кандидатов — [Д]:

| Класс положения | Ось вращения квантрона | Кандидат |
|---|---|---|
| сфера + кольцо | нормаль кольца / поперёк неё | **Qd** / **Qu** |
| тор + экваториальное кольцо | общая ось / поперёк неё | **Qs** / **Э-x** |
| тор + меридиональное кольцо | ось тора / нормаль кольца / третья ось | **Qc** / **Qt** / **Qb** |

**Э-x** — экваториальная фигура Qs, вращающаяся вокруг поперечной оси:
- у неё метки Qb («тор поперёк, кольцо поперёк») и та же симметрия (порядок 8);
- это Qb с исходного рисунка Автора (`Quantron.html`), до перерисовки 22.10;
- геометрия и кинематика касания её не исключают: она проходит, как Qs.

Канон исключает её только счётом «шесть типов» (A-3). «Из Qb получается латчер» объясняет, почему Qb — меридиональный конец (§ 2: у экваториального кольца латчерного положения нет), но не объясняет, почему Э-x не отдельное состояние. **Вопрос открыт:** нужен закон — или это седьмое состояние.

**4.2. Нотация Q_t2r2 сама неоднозначна.** Метки «тор поперёк, кольцо поперёк» носит всё семейство наклонов при оси вращения, перпендикулярной обеим осям: θ = 0° — Э-x, 0° < θ < 90° — наклонные, θ = 90° — Qb. Однозначность даёт только класс положения из КВ «Латчеры».

**4.3. Асимметрия Qs ↔ Qc** подтверждена и уточнена. Класс касания меняется сразу при уходе с θ = 0° и дальше постоянен до 90°. Qs — изолированная точка класса «касание по окружности» среди всех положений кольца у тора.
