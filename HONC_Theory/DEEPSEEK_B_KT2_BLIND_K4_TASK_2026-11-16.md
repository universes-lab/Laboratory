## 2. Что вывести

| № | Что | Форма ответа |
|---|---|---|
| 1 | ρ* каждого навеса H1, H2, H3 — корень условия касания из `fix` | градусы, до 0,01°; вилка [a, b] шириной не больше 0,5°, в которой лежит корень |
| 2 | Вердикт геометрии всей конфигурации | одно значение из словаря интерфейса |
| 3 | Вердикты J5-CANON и J5-EXT | по одному значению из словаря интерфейса |
| 4 | Касания | список пар объектов, которые касаются; у каждой пары — статус из словаря интерфейса |
| 5 | Рёбра графа J5 | список рёбер; у каждого — класс из словаря интерфейса |
| 6 | Проверки R-3 | для каждой пары колец навесов, к которой интерфейс применяет R-3: итог и полнота из словаря интерфейса |

Определения терминов и словари значений — только из интерфейса v6 → v7 → v7.1 и поправки 1.
