## 1. Главная ошибка — направление навеса

**Интерфейс v6, § 2 (М-14), дословно:** «e = s·e_x·cos ρ + (−e_z·cos ψ + e_y·sin ψ)·sin ρ».

Для прямой нити: e_x = x̂, e_y = ŷ (ось хозяина), e_z = ẑ (вдоль нити).
- **При ψ = 0:** e = (s·cos ρ, 0, −sin ρ) — навес отклоняется **назад, к предыдущему тору**, в плоскости нити x–z. Составляющей вдоль ŷ нет.
- **Тогда:** e ⊥ ŷ, по П-5 T_H = ŷ, а d = 2 — закрытая форма. Не 1,087 и не 1,5.

У тебя e = cos ρ·x̂ + sin ρ·ŷ. Из-за этого неверны все числа в `K5-POS-uniform-shift`, `K5-NEG-single-deviation` и в разборе Б-8. Пересчитай их по формуле выше, Э-А.

**Как пример — одиночное отклонение,** H2: ρ = 5°, ψ = 0.
- A_H2 = (2·cos 5°, 0, 4 − 2·sin 5°);
- H1 = (2, 0, 2), H3 = (2, 0, 6).
- H2 сдвинут к H1. Отсюда проникновение H1–H2, а с H3 зазор положителен, касания нет.
- Проникновение — только с H1, не с обоими соседями.

## 2. Геометрия и J5 — всё ещё смешаны

В `K5-NEG-single-deviation` написано «J5-CANON: FORBIDDEN (цикл разорван проникновением)». Это неверно.
- Граф J5 строится из касаний (`IMPOSED`, `CANDIDATE`). Пара с проникновением — не касание и не ребро.
- Без рёбер H1–H2 и H2–H3 граф — дерево, значит `J5-CANON: PASSED`.
- Запрет здесь — **геометрический**: `FORBIDDEN` по G-4.

## 3. Лента при 30° — построена не то

**Лента — это гребёнка К5 при ρ = 30°**, а не синтетический треугольник. Источник: Раунд 3а, К3 (ρ = 30°, ψ = 0, δ = 0 — касание с предыдущим тором) и К5 («равномерный сдвиг … при 30° треугольная лента»).

**`K5-NEG-band-30`:**
- навесы на хозяевах 1, 2, 3, сторона +1;
- ψ = 0, δ = 0;
- `rho: null` и `fix` с предыдущим тором (T0, T1, T2), вилка [29,5; 30,5].

**Касания:**
- с предыдущим тором — `IMPOSED`, П-8(б);
- навес–навес — `IMPOSED`, П-8(г), вариант с уравнением касания.

**Циклы:** T_{k−1}–T_k–H_k — треугольники К3.

**Ожидаемое:** геометрия `PASSED`, `J5-CANON: FORBIDDEN` (Б-4, М-6). Это прямой аналог К3: геометрия допустима, J5 запрещает.

**`K5-UNRESOLVED` — аналог Б-8:** то же построение, но `rho: 30` числом, без `fix`.
- По формуле § 1: H_k = A_k + 2·(cos 30°, 0, −sin 30°) = A_k + (√3, 0, −1).
- Отсюда |H_k − A_{k−1}| = |(√3, 0, 1)| = 2, и разность центров перпендикулярна ŷ. Касание с предыдущим тором — аналитический ноль, но тождеством не установлено.
- Значит, `CANDIDATE`, ветви расходятся, итог — `UNRESOLVED`.

**REFERENCE GAP № 9 и № 10 не нужны:**
- **№ 9** исходит из ошибки. Каноническое чтение J5 требует установленной параллельности и установленного типа (K-3, М-1), а **не колец**. Ребро T1–H1 в К3 — `CONTACT-ONLY` и при этом каноническое.
- **№ 10:** вариант с «ψ, отличающимися на 10⁻³°» зависит от точности ядра. Такое испытание не годится — прошлая сверка, § 2, п. 3.

## 4. Узел К4 на всех хозяевах — `REFERENCE GAP` № 8

- **«На всех хозяевах»** — на хозяевах гребёнки К5, то есть 1, 2, 3. Тогда `fix` с T0, T1, T2, и проблемы «нет предыдущего тора» не возникает. Хозяева 0, 2, 4 противоречат словам «на всех хозяевах».
- **Предлагаемое чтение «все вверх и через один»:**
  - все три навеса с параметрами К4 (ψ = 54°, δ = 10°);
  - либо через один — К4 и его зеркальная пара (ψ = 306°, δ = −10°; спецификация, А-4).

  Оставь это как `REFERENCE GAP` с этим чтением.
- **Ожидаемое J5.** У каждого навеса есть касание с предыдущим тором (`fix`), значит, цикл T_{k−1}–T_k–H_k. Его рёбра — по расширению, потому что оси непараллельны. По строке К4 (§ 2.10, М-6; Б-2): **`J5-CANON: UNRESOLVED`, `J5-EXT: PASSED-EXT`**, а не «дерево, `PASSED`».

## 5. Кλ5 с кольцами — геометрия `UNRESOLVED`

Это решение № 5 из прошлой записки.
- В `Kλ5-W-even` кольца Q12 и Q34 лежат в плоскостях z = 0 и z = 2, обе содержат x̂ и ŷ. Это параллельные различные плоскости.
- У синтетических колец параллельность тождеством не устанавливается: П-9 — только для навесов. Значит, пара получает R-5, и **геометрия — `UNRESOLVED`**.
- `J5-CANON: PASSED` при этом остаётся.
- То же у глюона: кольца k и k+4.

Исправь ожидаемое. Либо дай вариант без колец: геометрия `PASSED`, рёбра `CONTACT-ONLY`.
