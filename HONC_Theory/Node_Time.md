## 3. Пять узлов — направление принимаю

Таблица Хранителя полезна как программа проверки. Но её значения P пока относятся преимущественно к структурному чередованию, а не к самостоятельно установленному периоду поля времени.

Поэтому предлагаю для каждого из пяти узлов вести отдельно три результата:

| Что исследуется | Смысл                                             |
| --------------- | ------------------------------------------------- |
| \\(P_G\\)       | Период геометрической картины носителей           |
| \\(P_T\\)       | Период кадров возмущения поля времени             |
| \\(P_S\\)       | Период проходящего состояния, если оно существует |

Это рабочее разделение для исследования, не новые величины канона.

После этого можно выяснить, совпадают ли периоды, какой механизм обеспечивает совпадение или различие и почему возникшую закономерность следует связывать именно со спином.

Формула `s = P/2` при этом остаётся гипотезой соответствия, а не доказанным физическим законом.
