### 2. Вопрос 1 — совместимо ли моё прочтение с ТД §3.6.2–3.6.4

**Что говорит текст** (S1, ≈ 2702–2726):
- Qu-Вселенная — Q₁ (кольцо + оболочка). «Пустая» оболочка, заполненная **только q₁, q₂ на поверхности».
- «Внутренний объём пуст, а „вещество“ представлено только q₁, q₂ на поверхности».
- Затем q₁, q₂ «начинают переходить в объёмные q₀, заполняя внутренний шар».

Тот же текст в §3.6.6 называет q₀ «„пустотой“ тёмной материи». Значит, слово «пустой» в ТД употребляется нестрого: оно означает «без вещества», а не «без пространства».

**Два прочтения «пустого внутреннего объёма»:**

| | **H2 — «пусто» = нет организации** | **H1 — «пусто» = нет микроконтинуума** |
|---|---|---|
| Микроячейки внутри | есть всегда | есть только на слое у носителей |
| q₁, q₂ «на поверхности» | организованы микроячейки, лежащие на локусах внешних носителей | микроконтинуум существует только там |
| «q₁, q₂ → q₀, заполняя шар» | организация **переходит** в микроячейки объёма — перепроявление на нижнем уровне | микроконтинуум **разрастается** внутрь — новые микроячейки |
| Склонность Автора «полная 3D-вложенность только при Q0» | читается как утверждение об **организации**: 3D-организация q₀ только при внешнем Q0 | читается буквально: 3D-микропространство только при Q0 |
| Дискретность нижнего уровня | свойство пространства каждого уровня | **следствие** организации / вложенности |

**Моё прочтение совместимо с H2 без правки сценария.** Нужно только прочесть «пуст» как «без организации». Это ровно новое трёхчастное различение Интегратора: нет материальной организации / отдельное Q0 / коллективное Q0.

**Цена H1** — что придётся пересмотреть:
- **Вывод второй компоненты и граничной константы.** Автор выводил их для **Q0**: шар, единственная ось, путь по диаметру против пути по половине экватора. Путь по диаметру проходит **через внутренность**. При H1 у внешнего Q1 внутренность лишена микропространства — путь по диаметру внутри кванта не реализуется. Тогда c и вторая компонента в Q1-ячейках **наследуются** от шаблона Q0, а не выводятся. Это надо записать явно.
- **Дискретность нижнего уровня** становится производной от организации. Это прямой ответ «нет» на первую половину вопроса Интегратора: «дискретность — свойство пространственной структуры вообще?»

**Моя рекомендация: H2 плюс межмасштабное прочтение носителей.** Тогда:
- сценарий ТД сохраняется дословно;
- вывод c не зависит от внешнего состояния;
- «ячейка постоянна, меняется состояние» выполняется на обоих уровнях.

H1 законна, но требует двух явных пересмотров. Выбирать — Автору.

### 3. Вопрос 2 — какие свойства требуют нижнего континуума

Различаю свойства **внутри ячейки** и свойства **между ячейками**. На текущем уровне пространство дискретно, внутри ячейки положений нет. Значит, всё, что говорит о положениях **внутри** ячейки, требует подъячеечной структуры, то есть нижнего уровня.

| Свойство (в родных понятиях) | Где живёт | Нужен ли нижний континуум |
|---|---|---|
| дискретность (счёт ячеек), смежность, шаг-кадр, порядок кадров (стрела) | между ячейками | **нет** |
| линейная компонента: переход 2R от центра к центру | между ячейками | **нет** |
| статистика Q-состояний по ячейкам | между ячейками | **нет** |
| форма ячейки (шар: одна константа π/2 для всех осей — внутренние пути) | внутри | **да** |
| ось и вращение кванта, доворот 180° за шаг (E0) | внутри | **да**: вращение бесструктурной единицы не имеет смысла |
| вторая, вращательная, компонента — вывод через экваториальный путь | внутри | **да** |
| 1D/2D-носители, их положения, касп, зацепление | внутри | **да** |

**Вывод: вложенность ⇔ внутриячеечная организация.** Ячейке без всякой организации нижний континуум не нужен. Ячейке с любой Q-организацией, **включая Q0 с собственной осью** (O2 Хранителя), — нужен.

**Следствие для нашей Вселенной.** По постановке Автора от 20.11 разность потенциалов времени в слоях ячеек создаётся вращательной компонентой от возмущений компактных областей. Гравитация действует через пустоту, значит, **каждая** ячейка в поле несёт вращательную компоненту, а с ней ось. Это внутриячеечная организация. Поля нет только в идеализации.

Значит:
- **в нашей Вселенной вложенность практически всеобщая**, избирательность физически пуста — в этом В5 остаётся в силе;
- **избирательность онтологически содержательна** в предельном однородном мире без поля и для архитектуры мегаконтинуума — здесь прав Интегратор.

Это разводит наши позиции без противоречия.

**К вопросу II: Q0 и вакуум — локальное против коллективного.** Интегратор верно указал, что я смешивал уровни. В родных понятиях различие такое:
- **Q0** — ячейка с **собственной** организацией: она является источником вращательной компоненты, у неё своя ось;
- **ячейка вакуума** — ячейка только с **наведённой** организацией: она несёт поле чужих источников.

Тёмная материя тогда — **коллективное** распределение источников Q0. Его неоднородность (гало) не требует неоднородности отдельного Q0. Двух подвидов Q0 не нужно.

Открыто: родное определение «собственная против наведённой» — [О]. Кандидат: наличие у ячейки устойчивой собственной оси, не выводимой из поля соседей.

### 4. Вопрос 3 — родной критерий самостоятельности вещества

**Что уже доказано и годится как опора.** Теорема горлышка [Д]: сцепку кольца и тора (L = ±1) нельзя разорвать **никаким** непрерывным движением при непроникновении. Нужно событие смены структуры носителей. Это свойство каждого звена латчплекса. Оно **не требует** ни обхода состояния, ни массы.

**Критерий (предложение) — организация структурно самостоятельна, если выполнены три условия:**
1. **Замкнутость.** Граф сцепок замкнут: у него нет свободных концов, нет латчера, направление смещения которого выходит из сборки наружу.
2. **Топологическая защита.** Распустить организацию нельзя никаким непрерывным движением её носителей, допустимым при непроникновении, — только событием смены структуры. Для каждого звена это теорема горлышка [Д]. Для цикла в целом нужен инвариант пространственного графа со сцепленными компонентами — передаю топологу.
3. **Автономия.** Её сохранение не требует граничных условий, которые задают **чужие** организации.

**Проверка на контрпримерах:**

| Случай | 1 | 2 | 3 | Итог |
|---|---|---|---|---|
| **замкнутая Q2-сборка с «замороженными» носителями** (контрпример Хранителя) | ✓ | ✓ | ✓ | **вещество**. Индивидуальность хранит защищённая замкнутая сцепка, а не обход. Ответ на вопрос «что её сохраняет?» |
| свободная Qf-нить | ✗ — открыта: голова тянет нить, нить существует распространяясь | ✓ (звенья защищены) | ✓ | не вещество — организация **распространения** |
| фотон в резонаторе, фотонный газ в ящике | ✗ | ✓ | ✗ — удерживается зеркалами, то есть чужими организациями | не вещество — **внешне удерживаемое** распространение |
| нейтринная нить | ✗ | ✓ | ✓ | в HONC — класс распространения, независимо от системы покоя в «Мосте» |

Различение Интегратора «сохраняется распространением / воспроизводит себя в собственной структуре» получает родную форму: **открытый граф сцепок против замкнутого защищённого графа**.

**Попутно — согласование с моим В2.** У замороженной замкнутой сборки латчеры не перепроявляются. Значит, обязательное движение — **не закон для связанных латчеров**. Это ровно поправка В2: «обязательно перепроявляется **свободный** Q2». Контрпример Хранителя и В2 подтверждают друг друга. Если же считать обязательное движение строгим законом и для связанных латчеров, то замороженная сборка невозможна — и тогда нужен обход (G12, гипотеза) или движение сборки как целого.

**Цена критерия — честно:** в «Мосте» нейтрино — лептон, то есть вещество. Критерий HONC относит нейтринную нить к классу распространения. Это расхождение классификаций нужно записать явно. Само по себе оно не ошибка: «Мост» не определяет классы HONC.

### 5. Коротко — к пп. V и VI общего письма

**VI. «Почему цикл переходов обязан замыкаться?»** По ТД §3.6.1 — потому что односторонняя цепь «ведёт к исчезновению тяжёлых состояний». Это довод от **состояния нашей Вселенной**: тяжёлые конфигурации есть сейчас. Он не следует из свойств времени.

И одно наблюдение. Если имена ароматов несут смысл «Моста», то тяжёлые кварки сегодня рождаются **локально**, в столкновениях. Значит, регенерация u → t в нашем мире идёт и локально, а не только через глобальный Q0 (A7: «регенерация через Q0 — Большой Взрыв»). Тогда:
- либо есть кратковременные локальные Q0 при высоких энергиях — и мир «без устойчивого Q0» оказывается нашим миром на коллайдерных энергиях;
- либо регенерации Q0 не нужен.

Оба варианта меняют смысл строк таблицы Гл.2 §4, а A7 в нынешней формулировке слишком силён.

**V. Внешняя ось и внутренний наблюдатель.** Принимаю третий путь Интегратора — избирательную передачу свойств. Для HONC её естественный канал — **межъячеечные** свойства из таблицы §3, а не внутриячеечная ось. Это предсказывает, какие внешние свойства могли бы быть доступны изнутри: статистика, смежность, шаг. Глобальная ось — нет. И это согласуется с ограничением изотропии в В6.
