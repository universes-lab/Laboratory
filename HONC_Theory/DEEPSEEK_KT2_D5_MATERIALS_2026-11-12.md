## 2. Построение (G-7): точные определения

Каждый Qf — тор со своим кольцом. Кольцо тора k продевает тор k и следующий тор нити. Кольцо последнего тора свободно: строится тем же правилом звена, но в его второй точке тора нет.

**Начало.** Тор T0: центр A₀ = (0, 0, 0), ось T₀ = +ŷ; начальное направление нити e_z = +ẑ.

**Рамка узла k** — для тора k с осью T_k и входящим направлением e_z (направление звена, пришедшего в тор k; для k = 0 — +ẑ):
- e_y = нормированная часть T_k, перпендикулярная e_z. Если она вырождена — e_y = нормировка (e_z × x̂);
- e_x = e_y × e_z.

**Звено k** из тора k, параметры (θ, φ, δ):
- направление: u = e_z·cos θ + (e_x·cos φ + e_y·sin φ)·sin θ;
- зеркальная ось: T′ = T_k − 2(T_k·u)·u;
- ось следующего тора: T_{k+1} = поворот T′ на угол δ вокруг n = нормировка(u × T_k), по правилу правой руки;
- δ = 0 — зеркальное звено;
- расстояние d:
  - зеркальное звено: d = 2(½·√(1 − (T_k·u)²) + ½);
  - незеркальное: d — корень уравнения «зазор G-4 = 0» вдоль u, с вилкой и проверкой единственности;
- центр следующего тора: A_{k+1} = A_k + d·u;
- кольцо k — плоский эллипс длины 2π через A_k и A_{k+1}, касательный к T_k в A_k и к T_{k+1} в A_{k+1} (G-2). Как кольцо записывается в протоколе и с какой точностью — § 6.5;
- последнее звено строится по тому же правилу с явно заданными (θ, φ, δ). Его кольцо свободно: тора в точке A_n нет;
- **зеркальное звено** (δ = 0) — конвенция модели [Г] (Раунд 3а, § 1). Ядро её не подставляет: δ всегда приходит из входа, а протокол помечает каждое зеркальное звено (§ 6, `conventions`).

**Навес** — на торе-хозяине h нити, сторона s ∈ {+1, −1}, рамка узла h:
- в координатах (ρ, ψ, δ): e = s·e_x·cos ρ + (−e_z·cos ψ + e_y·sin ψ)·sin ρ.
  - ρ — отклонение от поперечного направления s·e_x.
  - ψ = 0 — отклонение назад, к предыдущему тору (−e_z); ψ = 180° — вперёд; ψ = 90° — вдоль оси хозяина.
- в координатах сцены захвата (α, λ, δ): e = cos λ·(s·cos α·e_x + sin α·e_y) − sin λ·e_z.
  - α — азимут от экватора хозяина к его оси; λ — отклонение назад.
  - Перевод: cos ρ = cos λ·cos α; ψ = atan2(cos λ·sin α, sin λ). При ρ = 0 угол ψ не определён — тогда перевод не выполняется, и навес задаётся напрямую в (ρ, ψ, δ).
- тор навеса и его кольцо строятся по правилу звена из хозяина с u = e и данным δ.

  Кольцо навеса продевает навес и хозяина.

## 3. Свидетельства построения: правила (П-1…П-8)

| П-1 | T₀ ⊥ e_z (тождество) | Начало нити |
| П-2 | u ⊥ T_k (тождество) | T_k ⊥ e_z установлено и θ = 0 или φ ∈ {0°, 180°} — точные значения входа |
| П-3 | T_{k+1} = T_k (тождество) | Звено зеркальное (δ = 0 точно) и u ⊥ T_k установлено. Тогда отражение оставляет ось неизменной |
| П-4 | T_{k+1} ⊥ e_z следующего узла | Из П-3: новое e_z = u, а u ⊥ T_k = T_{k+1} |
| П-5 | T_навеса = T_хозяина (тождество) | δ = 0 точно и e ⊥ T_хозяина установлено: ρ = 0 или ψ ∈ {0°, 180°} точно, при T_хозяина ⊥ e_z хозяина |
| П-6 | `PARALLEL-ESTABLISHED` для пары | Оси пары равны или противоположны по цепочке тождеств П-3, П-5 или по явному объявлению входа (§ 4.3) |
| П-7 | Касание боковое по построению | Пара из П-6, и разность центров перпендикулярна оси по цепочке тождеств: все звенья между ними имеют u ⊥ T, установленное по П-2 или П-5 |
| П-8 | `IMPOSED` | (а) Сцепленная пара — звено с d из закрытой формы или доказанного корня. (б) Конфигурация задана уравнением касания (§ 4.2), корень доказан и единствен в вилке. (в) Явное объявление симметрии во входе — только в синтетических случаях, с записью основания |

### 4.1. Конфигурация нити с навесами

```json
{
  "id": "K4",
  "thread": { "n": 5, "links": [
    { "theta": 0, "phi": 0, "delta": 0 }, { "theta": 0, "phi": 0, "delta": 0 },
    { "theta": 0, "phi": 0, "delta": 0 }, { "theta": 0, "phi": 0, "delta": 0 },
    { "theta": 0, "phi": 0, "delta": 0 } ] },
  "hangs": [
    { "host": 2, "side": 1,
      "coords": "rho-psi", "rho": null, "psi": 54, "delta": 10,
      "fix": { "kind": "contact", "free": "rho", "with": "T1", "bracket": [57.0, 57.5] } }
  ]
}
```

- `thread.n` — число торов нити.
- `thread.links` — ровно n записей (θ, φ, δ) для звеньев 0…n−1, включая последнее, со свободным кольцом.
- `hangs[]` — навесы:
  - `coords`: `"rho-psi"` или `"alpha-lambda"`;
  - параметры `rho`, `psi`, `delta` или `alpha`, `lambda`, `delta`.
- **Значений по умолчанию нет.** Отсутствующий параметр — `input_error`. Исключение — свободный параметр уравнения касания: он равен `null` (§ 4.2).
- Числа входа понимаются как точные десятичные значения. Ядро заключает их перевод в радианы в вилку.


### 4.3. Синтетические объекты

Для испытаний вне построения нити:

```json
{
  "id": "B10-like",
  "tori": [
    { "name": "S1", "A": [0, 0, 0], "T": [0, 1, 0] },
    { "name": "S2", "A": [2, 0, 0], "T": [0, 2, 0] },
    { "name": "S3", "A": [0, 0, 2], "T": { "sameAs": "S1" } }
  ],
  "rings": [
    { "name": "Q1", "C": [1, 0, 0], "E1": [1, 0, 0], "E2": [0, 1, 0], "s1": 1, "s2": 1,
      "threads": ["S1", "S2"] }
  ],
  "declare": [ { "kind": "symmetry", "pair": ["S1", "S3"], "contact": "IMPOSED", "basis": "text" } ]
}
```

- **Тор:** центр `A`, ось `T` — числа или `{ "sameAs": имя }` / `{ "oppositeOf": имя }`. Ссылка — явное тождество (П-6). Числовая ось тождеством не является, даже если совпадает с другой поразрядно. Числовую ось ядро нормирует; результат нормировки — вилка.
  - **Почти параллельные оси в испытаниях** (версия 6). Определённый итог `PARALLEL-UNCERTAIN` даёт только численно параллельная ось без `sameAs`: в примере у S2 ось [0, 2, 0], тогда как у S1 — [0, 1, 0]. Истинное abs(T_A × T_B) = 0 лежит в любой верной вилке.
  - Ось с малым, но ненулевым отклонением — например, 10⁻¹⁵ — вилками отделима от параллельной. Её классификация зависит от ширины вилок и интерфейсом не задаётся.
  - Определённый итог `NON-PARALLEL` даёт отклонение, много большее ошибки вычисления.
- **Ортонормированность** `E1`, `E2` ядро проверяет по вилкам. Не подтверждена — `input_error`.
- **Кольцо:** центр `C`, ортонормированные `E1`, `E2`, полуоси `s1`, `s2`; эллипс C + s1·cos t·E1 + s2·sin t·E2.
  - `threads` — какие торы оно продевает. Это **объявление входа**: построением оно не выводится.
    - Ядро проверяет его на совместимость: вилки невязок должны содержать 0. Невязки — прохождение кольца через центр тора, касание оси, ось в плоскости кольца.
    - Если хотя бы одна вилка отделена от нуля — `input_error`.
    - Совместимость — не сертификат. В протоколе она записывается как посылка входа, и проверка «кольцо против продетого тора» (G-5б–г) идёт при этой посылке.
    - Продетый тор с наклонённой осью требует кольца, касательного к **этой** оси в его центре (версия 6). Кольцо, касательное к оси другого тора, с ним несовместимо — `input_error`.
- **`declare`** — явные объявления. Допустимы ровно два вида:
  - `{ "kind": "symmetry", "pair": [A, B], "contact": "IMPOSED", "basis": текст }` — П-8(в);
  - `{ "kind": "type", "pair": [A, B], "type": "SIDE" | "AXIAL", "basis": текст }` — тип по объявлению.

  Любой другой вид — `input_error`. В протоколе объявления помечаются как объявления входа.
- **Без объявления типа** тип синтетической пары не установлен. Ядро может лишь сертифицировать смешанный тип (§ 3).
- Синтетические кольца не обязаны иметь длину 2π: ядро проверяет длину только у колец, построенных по § 2.
- Синтетическое кольцо попадает в протокол записью § 6.5 с `source: "synthetic"`. Его вилки — перевод чисел входа, и ширины печатаются так же.


### М-17. Сводный документ по λ-состоянию, § 4.1–4.2: формула касания; глюон, W, Z

`HONC_Q1_Lambda_State_2026-10-17.md`, строки 242–270

**Точная формула контакта.** d = 2·h(u∥), где u∥ = sin β · cos(π/N) — проекция нормали к биссекторной плоскости на ось тора. Для круглой трубки h = a·√(1 − u∥²) + b. Для общей трубки с полуосями b_r, b_z: h = a·|u⊥| + √(b_r²u⊥² + b_z²u∥²). Соседние торы — зеркальные отражения друг друга в биссекторной плоскости, поэтому формула точна для любой формы трубки.
