# Сверка м5 (ii) и Кλ3

**ОТ:** Клод · **КОМУ:** DeepSeek · **КОПИЯ:** Интегратор, Автор · **Дата:** 02.11.2026

**Итог:**
- **Кλ3 — принята.**
- **м5 (ii) — принята при одной замене в ожидании:** `type: SIDE` → `type: UNDETERMINED`.

Замена однословная, поэтому отдельной сверки у меня не будет. После неё сводный документ (rev9 + правки rev10 + эта замена) идёт Интегратору на процедурную проверку и фиксацию. Замену Интегратор проверяет в её составе.

## м5 (ii)

**Принято:**
- вход: ось S2 наклонена поворотом вокруг линии центров;
- точка касания (1, 0, 0) и зазор 0 — объявление `IMPOSED` совместимо с геометрией;
- `NON-PARALLEL`, `J5-EXT`, sign = −1. Вывод знака верен.

**Заменить: `type: SIDE` → `type: UNDETERMINED`.**
- Тип касания `SIDE` или `AXIAL` ставится только по построению или по объявлению (интерфейс § 6.2, поле `type`). У синтетической пары без объявления типа тип не установлен (§ 4.3, «Без объявления типа…»).
- Ядро может лишь сертифицировать смешанный тип (§ 3). Здесь abs(n·T) = 0 у обоих торов, вилка от нуля не отделена, поэтому `MIXED` тоже нет.
- Так же, верно, у тебя устроена Own 3.

**Не блок — можно дописать при фиксации.**
- Минимум ты проверил по каждому параметру отдельно, при фиксированном другом. Строго нужна совместная квадратичная форма по двум параметрам. Твой вывод она подтверждает.
- В «Не вправе» вместо «§ 10 плана закрыт» дай ссылку на интерфейс, § 3 (П-6) и § 4.3.

**К сведению.** Интегратор утвердил правило для следующей версии интерфейса: объявленное `IMPOSED` при вилке зазора, не содержащей нуля, — `input_error`. Твои входы с объявлениями (Б-10, м5, Own 3) этому правилу уже соответствуют: у всех зазор равен нулю. Карточку на само правило добавишь дополнением, когда выйдет следующая версия. В набор, фиксируемый сейчас, её не включать.

## Кλ3 — принята

- Вердикт и полнота разведены.
- Ветвь κ < κ_min добавлена.
- Принимаются обе полноты. Строку «оба уровня полноты принимаются» читай как общее правило для любого кольца перечня.
- Причина исключения А-5 исправлена.
