## 1. Решения по пробелам

### № 4 — синтетический нечётный цикл: `FORBIDDEN` достижим

**Правило совместимости** (интерфейс, следующая версия; Интегратор, 02.11, `APPROVED`): объявленное `IMPOSED` даёт `input_error`, только если сертифицированная вилка зазора **не содержит 0**. Если 0 в вилке, противоречие не доказано, и объявление принимается.

**Как этим пользоваться:**
- Координаты пишутся с полной точностью, 17 значащих цифр: `1.7320508075688772`. Истинный зазор тогда порядка 10⁻¹⁶, то есть объявление совместимо.
- С тремя знаками (`1.732`) зазор отрицателен, порядка 10⁻⁵, — это `input_error`.

**Построение:**
- три тора, оси через `sameAs` — **в JSON, а не только в тексте**: сейчас у тебя у всех трёх числовая ось `[0, 1, 0]`;
- `declare symmetry IMPOSED` на три пары, `declare type SIDE` на три пары;
- знак каждого ребра −1 — выводится, Э-А: при одинаковых осях и боковом касании v_B = −v_A;
- ∏ = −1, значит **`J5-CANON: FORBIDDEN`**.

Если ядро всё же выдаст `input_error`, это результат прогона для разбора, а не повод менять ожидание.

**Кольца в синтетике** (§ 4.3): кольцо касается оси каждого продетого тора в его центре, ось лежит в плоскости кольца.
- При осях ŷ плоскость кольца обязана содержать ŷ: `E2 = [0, 1, 0]`.
- У тебя `E2 = [0, 0, 1]` — это `input_error`.
- Для проверки чётности J5 кольца не обязательны: без них рёбра — `CONTACT-ONLY`. Карточка называет, какой вариант выбран.

### № 5 — W и глюон

**Что проверяет Кλ5 в КТ-2:** чётность J5 на цикле графа касаний замкнутой цепи (план, § 6.2: Б-4 — Э-С + Э-П).
- При рабочем наклоне β оси торов не параллельны. Чтение тогда — `J5-EXT` (K-3), и канонический `PASSED` недостижим.
- В источнике, в таблице глюона, есть строка «0° — плоское кольцо».

**Решение:**
- **Положительные карточки Кλ5** — плоские замкнутые цепи, β = 0: N = 4 (W) и N = 8 (глюон).
- **Торы** — в вершинах правильного N-угольника со стороной 2, в плоскости, перпендикулярной осям.
  - Квадрат точен: (0, 0, 0), (2, 0, 0), (2, 0, 2), (0, 0, 2) при осях ŷ.
  - Восьмиугольник — с 17 знаками, по № 4.
- **Оси и касания:** оси `sameAs`; касания соседей — `declare symmetry IMPOSED` и `declare type SIDE`.
- **Ожидаемое:** `J5-CANON: PASSED`, так как ∏ = (−1)ᴺ = +1.
- **Кольца**, если включены, — окружности радиуса 1 через центры соседей, плоскость содержит ось.
  - Противоположные кольца (k и k + N/2) лежат в параллельных плоскостях. У синтетических колец параллельность тождеством не устанавливается: П-9 — только для переноса в гребёнке.
  - Поэтому эти пары получают R-5, и **геометрия — `UNRESOLVED`**. Это ожидаемый итог такой карточки: геометрия и J5 раздельно.
- **Без колец** соседние касания — `CONTACT-ONLY`, несоседние торы разнесены, геометрия — `PASSED`.
- **Вариант с рабочим β** в Б-4 не входит. Хочешь — дай одну документирующую карточку с чтением `J5-EXT`, без канонического ожидания.

### № 6 — Z

Чтение принимаю: в М-9 «чётные циклы Z, W, глюон» — циклы цепи латчеров. У Z в графе касаний одно ребро, и цикла J5 нет.

Карточка Z — документирующая: ожидаемое `J5-CANON: PASSED` (циклов нет). Она проверяет, что два звена между одной парой торов не дают цикла J5. В Д-6 — по желанию.

## 2. Поправки к части 2

1. **К6 — координаты.** Нить идёт вдоль z, оси — вдоль y. Правильно: A_H1 = (2, 0, 2), A_H2 = (−2, 0, 4), A_H3 = (2, 0, 6). У тебя перепутаны y и z. Расстояния √20 и 4 верны.

3. **`K6-UNRESOLVED-near-contact` не годится.**
   - При ρ ≈ 90°, ψ = 90° навес идёт вдоль оси хозяина, и это уже не чередование К6.
   - Ожидание `CANDIDATE` зависит от точности ядра при зазоре порядка 10⁻¹⁰. Испытание не может от этого зависеть.

   **`UNRESOLVED` строится на точном аналитическом нуле без тождества.** Источник — Б-8, интерфейс, § 4.2: «Без `fix` все параметры берутся как числа. Касание с зазором, вилка которого содержит 0, тогда получает `CANDIDATE` (K-1). Так задаётся испытание Б-8».
   - Пример: навесы с ρ = 30°, ψ = 0, δ = 0, заданные числом, без `fix`.
   - Касание с предыдущим тором — аналитический ноль (sin 30° = ½), но не установлено. Значит, `CANDIDATE`, ветви расходятся.
   - Годится и для К5 (лента без `fix`), и для К6.
4. **Часть 1, `K5-UNRESOLVED-candidate`** — разные ρ сдвигают H2 к H1. Это проникновение (`FORBIDDEN`), а не `CANDIDATE`; вывод — Э-А. Замени по п. 3.
5. **Часть 1, `K5-POS-K4-node`.**
   - «Узел К4» — параметры К4: ψ = 54°, δ = 10°, ρ — корень касания с предыдущим тором.

   - Для «все вверх и через один» предложи чтение, согласное с узлом К4. Спецификация, А-4, называет зеркальную пару: ψ = 306°, δ = −10°. Если источник не решает — `REFERENCE GAP` с этим чтением.
