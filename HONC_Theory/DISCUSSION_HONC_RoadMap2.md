3. Скелет размеров
Ободы на c, запас и энергия сохраняются:
R_k / R₀ = (E₀ / E_вращ,k) • (Σ|Lᵢ| / |ΣLᵢ|)
Первый множитель — какая доля энергии осталась во вращении, если часть ушла в третью компоненту. Второй — во сколько раз скалярная сумма запасов больше векторной. Оба множителя не меньше единицы. [Д при этих условиях]

5. Q0 — тёмная материя
Образ «пыль сквозь пальцы» [М] точно попадает в наблюдательный портрет тёмной материи. Она тяготеет и собирается в гало, но не сталкивается: проходит сквозь себя и сквозь вещество. В скоплении «Пуля» масса отстала от газа. Тёмная материя не охлаждается и не образует компактных структур.
Напряжение есть одно. Q0 у тебя — однородный фон, задающий диапазон «0 – c». Но однородный фон не тяготеет: в уравнение входит только избыток над I₀. А тёмная материя неоднородна, она в гало. Справка Мастера Имен: Naming Synchronization Note для Grok, Claude, Хранителя и остальных
### HONC — Naming Synchronization
**Грамматика Q2-семейства:**  
**latcher** — элемент → **latching** — процесс соединения → **latchplex** — связный объект / семейство объектов → **latchform** — конкретная морфология latchplex.
| Термин | Синхронизированное употребление |
|---|---|
| **Quantron / квантрон** | Элементарный объект Q1. Шесть вариантов Q1 соответствуют шести ароматам квантронов. Не использовать `quantron` для облачных структур верхних уровней. |
| **Latcher / латчер** | Элементарный объект Q2; динамический тип, способный двигаться и соединяться с другими латчерами. Основные варианты: **Qf** и **Qν**. |
| **Quantum Spiritus Sancti (QSS)** | Официальное собственное имя Q3. В строгом описательном контексте допустимо **transitional Q3 state / liminal Q3 state**. Русское «Квант Святого Духа» — буквальное авторское прочтение имени. |
| **Qu … Qb / Q_s1r1 … Q_t2r2** | Обозначения шести ароматов Q1-квантронов по комбинациям sphere/torus + ring относительно опорной оси. |
| **Latchplex** | **Общее имя класса связных Q2-образований** из латчеров — независимо от масштаба, размера, замкнутости, формы и Qf/Qν-базы. Сюда входят короткие фрагменты, λ-сборки, кольца, жгуты и более крупные связанные структуры. |
| **Latchform** | Морфология конкретного latchplex. Основные описательные признаки могут комбинироваться: **open / closed / coiled / extended** и т. п. `Latchform` не является отдельным классом объектов. |
| **Latch fragment** | Короткий связный открытый фрагмент из латчеров; частный случай latchplex. Не обязательно считать его «прото-» будущей частицы. |
| **λ-molecule / λ-молекула** | Специальный подкласс Qf-latchplex: замкнутые элементарные сборки **Z / W / gluon**. Не использовать как общее название всех latchplex. |
| **Closed Qf latchplex** | Формальное морфологическое имя замкнутой Qf-структуры. Если позднее будет установлен её статус предформы фотона, дополнительно допустим функциональный ярлык **proto-photon**. |
| **Closed Qν latchplex** | Формальное морфологическое имя замкнутой Qν-структуры. Если будет установлен статус предформы нейтрино, дополнительно допустим **proto-neutrino**. |
| **Bundle / жгут** | Протяжённая latchform. Фотонная и нейтринная ветви различаются Qf/Qν-базой; само слово `bundle` не задаёт статистику и конечную частицу. |
| **Protoquark / протокварк** | Коллективное монообразование из большого числа квантронов **одного из шести Q1-ароматов**. Это название определённой ступени Q1-структуры, а не общее имя всех Q1-коллективов. |
| **Parton / партон** | Рабочее имя более высокоуровневой структуры с бозонно-глюонной сборкой и одиночным зародышем-протокварком. Не смешивать с `protoquark`. |

Отдельно четыре коротких запрета участникам, потому что именно здесь старый словарь будет сам возвращаться:
**`quantron ≠ cloud`**,  
**`latchplex ≠ latchform`**,  
**`proto-photon / proto-neutrino ≠ morphology`**,  
**`protoquark ≠ family name for all Q1 structures`**.
