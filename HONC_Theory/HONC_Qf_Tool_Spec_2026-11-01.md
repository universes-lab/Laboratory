## 0. Коротко

1. **Ядро геометрии переписывается.** Прежний `core.js` годится как образец построения, но не как проверяющее ядро.
   - Новое ядро:
     - периметр кольца — через полный эллиптический интеграл (AGM);
     - минимумы расстояний — гарантированным одномерным поиском;
     - кольца — точными алгебраическими критериями.
   - У каждого результата — интервал ошибки.
2. **Вердикты:** `PASSED` / `FORBIDDEN` / `UNRESOLVED`.
   - `PASSED` — только при полноте `EXACT` или `CERTIFIED`.
   - Выборка без нарушений даёт `UNRESOLVED`.
   - Касание в пределах погрешности — кандидат, а не факт.
   - Положительный J5 при рабочем расширении — условный и показывается отдельно от канонического.
3. **Статика и пути различаются.** Отдельные статические конфигурации инструмент удостоверяет в R1 (§ 2.10): прямая нить, поперечный навес, плоский треугольник, окно К4 по геометрии, гребёнка, чередование.
   - Непрерывный путь до снятия TB-1 получает `PROVEN CONTINUOUS PATH` только в тривиальных случаях (без движения) или при отдельном доказательстве. Остальные пути — не выше `UNRESOLVED`.
4. **TB-2 и TB-4 для базовых случаев снимаются в R1.**
   - TB-2: кольцо плоское, его плоскость содержит ось каждого продетого тора. Значит, проверка «кольцо против своего тора» точно сводится к плоской задаче: эллипс против двух кругов.
   - TB-4: в базовых случаях соплоскостные кольца далеко разнесены, и разделяющая прямая находится в закрытой форме.
   - Препятствий выпуску среди базовых статических случаев нет.
5. **Отложено (R3):**
   - закон выбора пути;
   - П-Т и устойчивость;
   - перепроявление;
   - неплоские кольца;
   - точная форма J5 для непараллельных осей;
   - физическое время;
   - сцена С6.

| Итог J5 | Два независимых: `J5-CANON: PASSED / FORBIDDEN / UNRESOLVED` и `J5-EXT [Г, мост]: PASSED-EXT / FORBIDDEN-EXT / UNRESOLVED` | Конфигурация (K-6) |
| Постановка перестройки | `CONTINUOUS` — единственная поддерживаемая; дискретная — [О] (П-Т) | Вердикты путей и событий |
| Слой | `CARRIER` · `DIAGNOSTIC` · `CANDIDATE [Г, мост]` | Каждый показанный объект |

**Правило вывода вердикта.**
- Конфигурация `PASSED` ⇔ все её проверки `PASSED`.
- Хотя бы одна `FORBIDDEN` ⇒ `FORBIDDEN`.
- Иначе — `UNRESOLVED`.
- То же для участка и для пути.
- Итог J5 выводится отдельно по K-6 и в геометрический вердикт не входит.

## 4. Приложение С4-Т — постановка наблюдения (не требование R1)

*Разрешена только постановка (Интегратор 01.11). Расчётов замкнутой гребёнки нет и без отдельного решения не будет.*

- **Вопрос.** Существуют ли при заданных геометрических параметрах две допустимые замкнутые конфигурации гребёнки — с навесами наружу и с навесами внутрь?
- **Наблюдаемые:**
  - для каждой формы при заданном числе узлов и радиусе замыкания — вердикт допустимости по §§ 2.1–2.3 (тела, кольца, A-15) и итоги J5 (K-6);
  - для внутренней формы — запасы навес–навес у центра. Хранитель: внутренняя форма может не поместиться;
  - отдельно, позже — существует ли допустимый путь между формами. В 3D возможен обход через третье измерение, плоской картинки для запрета недостаточно (Интегратор).
- **Предпосылки и их статус:**
  - само замыкание гребёнки не факт: правило «звено по сумме супер-Z» — [Г], закона выбора пути нет. В наблюдении радиус и число узлов — входные параметры, заданные наблюдателем, а не результат;
  - счёт: замкнутая Qf-структура — один цикл [Д \| лемма ГП]; не больше одного навеса на тор цикла [Д \| A-15].
- **Что не утверждается:**
  - что две формы — разные топологические классы;
  - отождествление «наружу / внутрь ↔ XYZ / YXZ ↔ электрон / позитрон» — [Г] Хранителя, не принято;
  - сохранность спинового замка P = 1 у однорядной гребёнки — надо перепроверить (Хранитель), вне С4-Т.
- **Что решило бы вопрос** (позже, по отдельному решению):
  - внутренняя форма недопустима при всех разумных радиусах — двоичность снимается;
  - обе допустимы — следующий вопрос: связность (путь между формами), затем интерпретация.
