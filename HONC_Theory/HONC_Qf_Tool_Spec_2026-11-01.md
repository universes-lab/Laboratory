## 0. Коротко

1. **Ядро геометрии переписывается.** Прежний `core.js` годится как образец построения, но не как проверяющее ядро: его проверки выборочные, у каспа слепая зона, периметр кольца считается приближённой формулой.
   - Новое ядро:
     - периметр — через полный эллиптический интеграл (метод AGM);
     - все минимумы расстояний — одномерным глобальным поиском с гарантированной оценкой, ветвями и границами по Липшицу;
     - кольца — точными алгебраическими критериями.
   - Каждый результат проверки идёт с интервалом ошибки.
2. **Три вердикта проверки:** `PASSED`, `FORBIDDEN`, `UNRESOLVED`.
   - `PASSED` — только при полноте `EXACT` или `CERTIFIED`.
   - Выборка без нарушений даёт `UNRESOLVED` с пометкой «нарушений не обнаружено выборкой».
3. **Для первого выпуска (R1) всё выполнимо**, кроме одного места повышенного риска: пересечения двух колец в одной плоскости (TB-4). Такие пары есть уже в исходной прямой нити, поэтому R1 обязан их обрабатывать хотя бы консервативно: подтверждённое разделение — `PASSED`, иначе `UNRESOLVED`.
4. **Строгий сертификат пути (R2) упирается в TB-1:** нет гарантированных оценок скорости изменения зазоров при движении по параметрам. Пока TB-1 не снят, каждый непрерывный путь получает в лучшем случае `UNRESOLVED`. Это честное состояние инструмента, а не его дефект.
5. **Отложено (R3):**
   - закон выбора пути;
   - П-Т и устойчивость;
   - перепроявление;
   - неплоские кольца;
   - точная форма J5 для непараллельных осей;
   - физическое время;
   - сцена С6.

## 1. Словарь меток (нормативный)

| Группа | Значения | Где применяется |
|---|---|---|
| Уровень результата | L1 — найдено · L2 — проникновений не обнаружено · L3 — согласовано по J5 · L4 — достижимо · L5 — реализуется механизмом. **L5 не присваивается** | Каждый показанный результат |
| Полнота проверки | `EXACT` — закрытая форма или алгебра с изоляцией корней · `CERTIFIED` — гарантированная оценка ошибки · `SAMPLED` — выборка · `UNRESOLVED` — не разрешено | Каждая проверка |
| Вердикт | `PASSED` (только при `EXACT` / `CERTIFIED`) · `FORBIDDEN` (с ограничением и местом) · `UNRESOLVED` (с причиной) | Конфигурация, участок, путь |
| Класс касания | `STRUCTURAL` (сцепленная пара, проход кольца через касп) · `ALLOWED CONTACT` · `FORBIDDEN CROSSING` · `UNRESOLVED CONTACT` | Каждое касание 2D–2D, 1D–2D, 1D–1D |
| Чтение J5 | `J5-CANON` (параллельные оси; боковое — встречно, торцевое — вместе) · `J5-EXT [Г, мост]` · `J5-DEGENERATE(ε)` | Каждое касание 2D–2D |
| Слой | `CARRIER` · `DIAGNOSTIC` · `CANDIDATE [Г, мост]` | Каждый показанный объект |
| Научный статус | из источников: [К], [Д], [Д-Кл], [Г], [О], [мост]; плюс интеграционный `NOT INTEGRATED` | Результаты и контрольные случаи |

**Правило вывода вердикта.**
- Конфигурация `PASSED` ⇔ все её проверки `PASSED`.
- Хотя бы одна `FORBIDDEN` ⇒ `FORBIDDEN`.
- Иначе — `UNRESOLVED`.
- То же для участка пути и для пути целиком.
