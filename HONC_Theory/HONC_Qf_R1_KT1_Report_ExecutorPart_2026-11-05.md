**Причина [Г].**
- Кольцо проходит через касп, касаясь оси тора. Зазор до тела там равен нулю и растёт примерно как ½·κ·s², где s — длина дуги от каспа, κ = 2 − κ_r (записка κ_min, § «Ответ на замечание»).
- Поэтому наименьший зазор вне любой исключённой окрестности лежит на её границе и задаётся её размером:
  - прежнее ядро — шар радиуса 0,12;
  - новое — окно r₀ по параметру, около 0,10 по дуге.
- У К1 так же: «вне каспа» 0,0804 при окне 0,42. Это свойство окна, а не кольца (записка WP-2, § 2, оговорка; ГР-7в).

**Проверка предположения** [ОЦЕНКА, класс В; плавающая точка на записях колец нового ядра, не сертификат; `old_definitions.py`]:

| Определение | Значение |
|---|---|
| прежнее: шар 0,12, 240 точек от t = 0 | **0,00572** (эталон 0,0057) |
| прежнее: шар 0,12, 240 точек, сдвиг фазы выборки | [0,00423; 0,00586] |
| прежнее: шар 0,12, плотная выборка (20 000 точек) | 0,00424 |
| главный член ½·κ·s² при s = 0,12 | 0,0046 |
| новое: окно r₀ (сертификат ядра) | 0,00180 |

**Вывод исполнителя.**
- Эталон 0,0057 воспроизводится методом прежнего ядра на кольце нового ядра.
- Без смещения выборки величина прежнего определения ≈ 0,0042.
- Ни одно из чисел не характеризует кольцо само по себе. Инвариант касания — κ = 0,634, `EXACT`; он в спецификации уже есть.

**Нужно решение Интегратора — общее определение.** Варианты:
- (а) считать «запасом у каспа» пару «κ в каспе (`EXACT`) + сертифицированный запас вне окна с указанием окна»;
- (б) закрепить прежнее определение (шар 0,12) и сертифицировать по нему — отдельная задача по разрешению.
