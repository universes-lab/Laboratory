# HONC — образование протокварка. Коллективное Q1-состояние: минимальная постановка (З-6)

*24.10.2026. Клод (ведущий физической триады). Поручение Интегратора от 24.10, 13:58. Канон не менялся. Новых законов не вводил.*

```text

QUESTION: Чем коллектив Q1 одного аромата отличается от ансамбля независимых Q1 — и выводится ли такой коллектив из принятого через существующие структуры HONC?
```

**Короткий ответ.**
1. **Признаки коллектива** — пять (K1–K5, п. 1). Механизм образования из них отделён. Ансамбль, отобранный инструментом (этап А), даёт только K1, и то лишь по знаку: корреляция происхождения — ещё не отношение.
2. **В принятом есть ровно одно сохраняющееся отношение Q1 с Qf** — продевание кольца латчера через отверстие Qs (паспорт Qs, [Д]). У остальных пяти ароматов статического причала нет: у Qd и Qu нет отверстия, у Qc, Qt и Qb мешает меридиональное вращение.
3. **Теорема счёта колец (Т-1)** [Д | ЛМ1, A-5]. Если каждое кольцо латчера проходит ровно через два каспа (ЛМ1), то:
   - связная латчерная структура содержит не больше одного Q1;
   - структура с циклом (замкнутая) не содержит ни одного.

   Значит, никакая существующая структура Qf-инструментов не связывает два Q1, а по A-4 устойчивы только замкнутые.
4. **Вывод.** Коллективное Q1-состояние — связность и сохранность для двух и более Q1 — из принятого не выводится ни для одного аромата. Максимум, что выводится, — один Qs в центре открытого дерева причалов: «гражданин с причалами», а не государство.
5. **Минимальная недостающая посылка — З-6, уточнённая.** Она должна связывать два Q1-узла и может иметь одну из трёх форм:
   - **З-6а — топологическая:** кольцо латчера проходит больше чем через два каспа. Достаточно для Qs, и только для него.
   - **З-6б — нетопологическая сохраняющаяся связь** Q1 с сетью — например, по времени событий. Неизбежна для u и d.
   - **З-6в — прямое отношение Q1 — Q1.**

   Выбор между «протокварк — топологическое образование» и «нетопологическое» — кандидат развилки. Передаю его Интегратору: созрела ли она для Автора.

## 0. Рамка

- **Член коллектива** — Q1-квантрон одного из шести ароматов. По A-3 это возмущение ячейки, а не твёрдое тело.
- **Коллектив** — протокварк: монообразование из многих Q1 одного аромата (A-1, словарь).
- **Инструменты** — λ-молекулы, замкнутые Qf-латчплексы. По A-4 только они и устойчивы; Q1 сам не собирается.
- **Отношение между объектами** — ограничение, связывающее их допустимые состояния.
  - **Сохраняющееся отношение** снимается только событием (разрыв, переотображение), а не просто движением. Пример — топологическое зацепление при A-5 («связь тора и кольца не рвётся»).
  - **Модельное отношение** держится стенками аналога, как непроницаемость «твёрдого шара» этапа А.
- Опоры: A-1, A-3, A-4, A-5, A-11, A-14 (п. 4), ЛМ1 (вариант (а), A-6), паспорт Qs, этапы А и Б.

## 3. Причал по ароматам [Д при посылках паспорта Qs и ЛМ1]

Зацепиться с Q1 можно только через его отверстие. Кольцо, сцепленное с собственным кольцом Q1, обязано пересечь любую натянутую на него поверхность. Через тело это запрещено правилом ЛМ1: 1D-носитель не входит в тело, кроме точки каспа.

| Аромат | Тело | Причал в покое | Почему |
|---|---|---|---|
| **Qs** | тор + кольцо на экваторе, без меридионального вращения | **да** | отверстие и кольцо неподвижны как множества; продетое кольцо сцеплено с экваториальным, Lk = ±1 (паспорт Qs) |
| Qc | тор + кольцо в меридиональной плоскости, кольцо вращается меридионально | [О] | отверстие неподвижно, но собственное кольцо заметает сферу и периодически встречает продетое кольцо. Нужно знать, допустимо ли пересечение 1D-носителей, или принять чтение В3 (переотображение) |
| Qt | тор вращается меридионально | [О] | при непрерывной кинематике отверстие заметается; при В3 направление прохода переворачивается каждый шаг |
| Qb | тор и кольцо вращаются меридионально | [О] | то же; паспорт Qs: «сомнителен как центр» |
| **Qd, Qu** | сфера + кольцо | **нет** | отверстия нет. Кольцо Q1 лежит на сфере, и любая натянутая на него поверхность проходит через 2D-тело. Сцепиться можно только сквозь тело — по ЛМ1 нельзя |

- **Причал сам — фильтр по аромату:** в покое продеться можно только в Qs. Для структур из причалов K1 выполняется автоматически.
- Для u и d — самых нужных дальше, для нуклона — топологической связи с Qf в принятом нет вовсе.

## 4. Теорема счёта колец (Т-1) [Д | ЛМ1, A-5, вариант (а)]

**Посылки.**
- (П1) Латчер — тор с одной точкой каспа и одно кольцо (A-1, A-5). Все кольца, проходящие отверстие тора, проходят одну точку каспа (вариант (а)).
- (П2) Кольцо латчера проходит ровно через два каспа: свой и соседний (ЛМ1: «эллипс длины 2π через центры двух соседних торов»).
- (П3) Q1 даёт узел-отверстие (только Qs, п. 3), но не даёт продевающего кольца: собственное кольцо Q1 закреплено на его теле.
- (П4) Сохраняющиеся связи в структуре — только продевания (п. 2).

**Утверждение.** Пусть связная структура содержит m латчеров и q Q1-узлов. Тогда q ≤ 1. Если в структуре есть цикл (замкнутый латчплекс), то q = 0.

**Доказательство.** Граф инцидентности:
- вершины — m колец и m + q каспов;
- рёбра — прохождения кольца через касп, по (П2) их 2m.

Для связного графа число независимых циклов b₁ = Е − V + 1 = 2m − (2m + q) + 1 = 1 − q ≥ 0, откуда q ≤ 1. Замкнутость означает b₁ ≥ 1, откуда q ≤ 0. ∎

**Общая форма** (кольцо r проходит через k_r каспов, если когда-нибудь (П2) будет ослаблено):
- связность требует Σ_r (k_r − 2) ≥ q − 1;
- замкнутость требует Σ_r (k_r − 2) ≥ q.

Каждому Q1 в замкнутой структуре нужен один «лишний» касп на каком-нибудь кольце.

**Сверка с известным.**
- Глюон: m = 8, q = 0, b₁ = 1 — один цикл, как и есть.
- Qs в центре трёх прямых ветвей (паспорт Qs): q = 1, b₁ = 0 — дерево. Т-1 согласуется с обоими.

**Следствия.**
1. Ни одна латчерная структура при (П1)–(П4) не связывает два Q1. **K2 для q ≥ 2 через существующие структуры недостижим ни для одного аромата.**
2. Замкнутый латчплекс — единственное устойчивое по A-4 — Q1 не содержит. Сеть замкнутых инструментов с Q1 внутри связывает инструменты, а не Q1. Это строгая форма предупреждения Интегратора: «не подменять коллектив Q1 сетью λ-инструментов».
3. Единственная структура с Q1 — открытое дерево с одним Qs. Его устойчивость — только при G12 («причал сворачивает полёт», [Г]).

## 5. Что выводится и чего не хватает

**Выводится** [Д | п. 4]: самое большее — один Qs, сцепленный с открытым деревом латчерных ветвей (не больше трёх ветвей по A-15). Это одиночный Q1 с причалами, без K2.

**Не выводится:** коллективное Q1-состояние — K2 и K3 для двух и более членов — ни для одного аромата. Минимальной модели в принятом нет. Это строгий ответ на критерий Интегратора, при посылках (П1)–(П4).

**Минимальная недостающая посылка — З-6, уточнённая.** Нужно сохраняющееся отношение, которое соединяет два Q1-узла. Три формы, по возрастанию новизны:

| Форма | Что меняет | Даёт | Для каких ароматов |
|---|---|---|---|
| **З-6а** | ослабляет (П2): кольцо латчера проходит через три и более каспа. A-5 («форма кольца свободна — плоский овал или эллипс») этого не запрещает; запрещает построение ЛМ1 | замкнутые структуры с q Qs при Σ(k_r − 2) ≥ q; K1–K4 топологически | только Qs; Qc, Qt, Qb — при В3 и только если [О] п. 3 решится в пользу причала |
| **З-6б** | вводит сохраняющееся нетопологическое отношение Q1 с сетью — например, общую фазу событий; это расширение О-к за пределы покоя (A-11) | K2, K5 без отверстий | все шесть; **для u, d — единственный путь** при ЛМ1 |
| **З-6в** | прямое отношение Q1 — Q1 (A-4 запрещает самосборку, но не всякое взаимодействие — Интегратор) | K2 напрямую | все шесть |

**Различающее следствие** [Д | Т-1, п. 3]:
- Если протокварк — топологическое образование, а A-12 «бог = топология» [М] склоняет сюда, то в принятой геометрии он возможен только для s, и то лишь с З-6а. Для u и d — невозможен без пересмотра правила «1D-носитель не входит в 2D-тело, кроме каспа».
- Если нетопологическое — нужен З-6б для всех ароматов, и тогда признак K5 («общая временная характеристика») становится не следствием, а определением.

Это развилка, которую нельзя вывести из принятого. Вводить ни одну из форм я не стал. Созрела ли она для Автора — решает Интегратор.

## 6. К ответу Дипсика

- Признаки протокварка у Дипсика (моноароматность, протяжённость, устойчивость, общий ритм, отличимость) совпадают с K1–K5. Согласие полное.
- Его недостающая посылка — «притяжение связок одного аромата на конечном расстоянии (равновесие)» — сформулирована языком моста: притяжение, равновесие.
  - В родном языке сохранность — это не равновесие сил, а инвариант (зацепление при A-5) или условие на события.
  - В этой форме его посылка — частный случай З-6б. По Т-1 она не может быть топологической через существующие инструменты.
- Его мысль, что коллектив должен возникать через инструменты, верна для механизма. Но Т-1 показывает, что в принятом инструменты не могут связать два Q1 даже в принципе. Значит, «через инструменты» требует З-6а или З-6б.
