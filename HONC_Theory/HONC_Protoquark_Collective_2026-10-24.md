## 3. Причал по ароматам [Д при посылках паспорта Qs и ЛМ1]

Кольцо, сцепленное с собственным кольцом Q1, пересекает любую натянутую на него поверхность. В схеме ЛМ1 1D-носитель не входит в тело, кроме точки каспа (статус правила — на сверку Хранителю).

| Аромат | Тело | Продевание в покое | Почему |
|---|---|---|---|
| **Qs** | тор + кольцо на экваторе, без меридионального вращения | **да** | отверстие и кольцо неподвижны как множества; Lk = ±1 (паспорт Qs) |
| Qc | тор + кольцо в меридиональной плоскости, кольцо вращается | [О] | отверстие неподвижно, но кольцо Qc заметает сферу. Допустимо ли пересечение 1D-носителей — неизвестно; или нужно чтение В3 |
| Qt | тор вращается меридионально | [О] | при непрерывной кинематике отверстие заметается; при В3 направление прохода переворачивается каждый шаг |
| Qb | тор и кольцо вращаются меридионально | [О] | то же; паспорт Qs: «сомнителен как центр» |
| Qd, Qu | сфера + кольцо | нет — в схеме ЛМ1 | отверстия нет; сцепиться с кольцом Q1 можно только сквозь 2D-тело |

- Продевание в покое возможно только для Qs. Для структур из причалов отбор по аромату, таким образом, встроен — но только для Qs и только для этого типа связи.
- Для Qd и Qu связь с Qf через прохождение колец в схеме ЛМ1 не строится. Другие формы связи (З-6б, З-6в) для них открыты.

## 4. Лемма ГП — граф прохождений [Д | ГП-1…ГП-4, ЛМ1]

**Посылки:**
- **ГП-1.** Латчер — тор с одним отверстием (точкой каспа) и одно кольцо (A-1, A-5). Все кольца, проходящие отверстие тора, проходят одну точку каспа (вариант (а)).
- **ГП-2.** Кольцо латчера проходит ровно через два отверстия: своего тора и соседнего (ЛМ1: «эллипс длины 2π через центры двух соседних торов»).
- **ГП-3.** Q1 может быть узлом-отверстием (в покое только Qs, п. 3), но продевающего кольца не даёт: собственное кольцо Q1 закреплено на его теле.
- **ГП-4.** Рассматриваются только связи-прохождения кольца через отверстие.

**Граф прохождений** — двудольный граф:
- вершины — m колец и m + q отверстий, из них q принадлежат Q1;
- ребро — прохождение кольца через отверстие.

**Утверждение.** Если граф прохождений связен, то q ≤ 1. Если в нём есть цикл, то q = 0.

**Доказательство.** По ГП-2 рёбер 2m, вершин 2m + q. Для связного графа b₁ = E − V + 1 = 1 − q ≥ 0, откуда q ≤ 1. Цикл означает b₁ ≥ 1, откуда q = 0. ∎

**Общая форма** — если ГП-2 когда-нибудь ослабить, и кольцо r проходит через k_r отверстий:
- связность требует Σ_r (k_r − 2) ≥ q − 1;
- цикл требует Σ_r (k_r − 2) ≥ q.

**Сверка.**
- Глюон: m = 8, q = 0, b₁ = 1.
- Qs в центре трёх ветвей (паспорт Qs): q = 1, b₁ = 0 — дерево.

**Что лемма говорит и чего не говорит:**
- **Говорит:** через прохождения колец по схеме ЛМ1 два Q1 в одну связную структуру не соединяются. Отверстие Q1 может быть узлом только дерева прохождений, а не цикла.
- **Не говорит:**
  - о связях другого типа: временных, через среду, через сеть инструментов с законом сопряжения (З-7), о прямых Q1 — Q1;
  - о Q1, захваченном в камере инструмента. Такой Q1 — не узел графа прохождений: кольца глюона его отверстия не проходят (этап А, М6). Лемме он не противоречит;
  - о невозможности коллективного состояния вообще.

**Наблюдение** [Г, как рамка]: принятые отношения делятся на две группы.
- Одни **держат, но не связывают** несколько Q1 — топологическое прохождение.
- Другие **связывают, но не держат** — контакт J5, фазовое отношение.

Отсюда минимальная посылка — одно из двух:
- **закон сохранности** для связывающих отношений: удержание контакта или фазы инструментами (З-7) или на уровне Q1;
- **закон кратности** для держащего отношения (З-6а).

Прямое отношение Q1 — Q1 (З-6в) и коллективная динамика через среду остаются отдельными кандидатами вне этой схемы. Какая посылка первая — решение Интегратора; Автору — когда созреет развилка.
