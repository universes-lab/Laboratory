## 1. Что такое VS-1

Один законченный показ, который можно дать внешнему человеку:

- **Пролог** — педагогический маршрут от состояний кванта к латчерной нити. На нём держится вся система: статусы, грамматика переходов, сторож, два языка, камера.
- **Визуальный эталон Gluon-ring quay** — восьмизвенная сборка с центральной камерой по разрешённой ранней модели. Это проба презентационного качества.

**Порядок работ внутри VS-1 — сначала зрелище:**
- **шаг А** — визуальная проба эталона Gluon-ring, без интерфейса → вердикт Интегратора и Автора о выразительности. Проба **внутренняя**, не публикуется и не является научной сертификацией КТ-2: оцениваются только свет, камера, материалы, масштаб и выразительность;
- **шаг Б** — пролог с полной системой статусов;
- **шаг В** — сведение в один тур, приёмка.

## 4. Техническая архитектура — без собственного движка

- **Three.js**, закреплённая версия; ES-модули с CDN; WebGL2.
- **Постобработка:** свечение, туман, тональное отображение. Стеклянные материалы подбираются на шаге А по критерию производительности — физическое пропускание дорого, возможна своя френелевская оболочка.
- **Три независимых слоя:**
  - `core/` — геометрия и сторож. Чистые функции без Three.js, без материалов, камеры и эффектов: сторож от художественных решений не зависит (поправка В);
  - `data/` — описания сцен по контракту, реестр источников, два положительных списка (публичный и лабораторный);
  - `render/` и `i18n/` — модули сцен на Three.js; словари RU/EN.
- **Сборка** скриптом Node: две однофайловые страницы, `atlas_public.html` и `atlas_lab.html`. В публичную физически попадают только данные из публичного списка — скрытие кнопками не используется (поправка Е).
- **Сборка останавливается,** если:
  - публичная сцена ссылается на источник вне списка;
  - у элемента, сборки или перехода нет статуса или источника;
  - нет перевода ключа;
  - сторож не подтвердил конфигурацию или движение.
- **Качество:** три уровня детализации; режим без движения.

## 5. Сторож геометрии — двухступенчатый (поправка В)

**Ступень 1 — заранее, один раз, при сборке.** Каждая неподвижная конфигурация S1–S8 проверяется функцией проникновения с запасом. Где есть сертифицированные запасы — протоколы КТ-1, — берутся они.

**Ступень 2 — в браузере.** Разрешены только движения из классов с **доказанным инвариантом**. Тогда проверка дискретных кадров не нужна:

| Движение | Инвариант | Основание |
|---|---|---|
| вращение тела или кольца вокруг собственной оси симметрии | носитель переходит сам в себя | геометрия |
| вращение всей структуры как целого (меридиональное вокруг Z) | взаимное положение не меняется | геометрия |
| каноническое вращение кольца Qb вокруг диаметра, параллельного оси тора (Т1 по таблице типов; природа вращения — развилка [О]) | F = 1 − ρ ≥ 0 при любой ориентации | лемма Q1-01 [Д] |
| произвольный наклон кольца квантрона — **только Т2**: неподвижная цепочка положений, без плавной анимации | F = 1 − ρ ≥ 0 при любой ориентации | лемма Q1-01 [Д] |
| переключение между заранее проверенными конфигурациями | без промежуточных кадров | ступень 1 |

Свободное перетаскивание носителей в VS-1 не вводится. Для будущих произвольных траекторий нужна граница на интервал — например, через постоянную Липшица функции F. Это вопрос следующих этапов, не VS-1.

**Чего сторож не утверждает:**
- отсутствие проникновения не доказывает разрешённого физического перехода;
- геометрический инвариант не делает смену положений движением Т1;
- самоповорот симметричного носителя — изобразительная анимация канонического вращения, а не доказанная эволюция.

Об этом сказано в легенде.

## 8. Как добавляются остальные quay

Каждый quay — это файл данных по контракту, модуль сцены (сценография свободная) и строки в реестре источников и положительных списках.

- **Клод_Б** делает Z, W и H-Qs по тому же контракту, со своей сценографией.
- **Клод_А** делает Electron-node candidate и полный Gluon-ring — после ворот КТ-2, — и интегрирует все пять сцен в оболочку.
- **Перекрёстная проверка:** Клод_Б смотрит понятность Gluon-ring, Клод_А — научную дисциплину сцен Клода_Б; Грок удостоверяет соответствие источникам; Интегратор сводит в один продукт.
