## 1. Что делает запуск

Сценарий `kt1_isolated_run.sh` с помощником `py_guard.py` прилагаются для проверки.

1. **Контрольная сумма** архива сверяется с суммой, которую зафиксировал Автор. Не совпала — отказ, запуска нет.
2. **Распаковка** в новую пустую папку прогона. Печатается опись файлов с sha256.
3. **Поиск упоминаний ядра** и внешних путей в исходниках (`scan.txt`) — для сведения.
4. **Ядро — только для Д-3.** Замороженный архив ядра кладётся в папку прогона после сверки его суммы `ecb35112…268ea`. Для скриптов А-5 ядра в папке прогона нет.
5. **Запуск без изменений:**
   - **Node.js** — с моделью разрешений (`--permission`): чтение и запись только внутри папки прогона; дочерние процессы и рабочие потоки запрещены.
   - **Python** — через `py_guard.py`, правило то же (audit hook): открывать файлы можно только в папке прогона и в стандартной библиотеке; процессы и сеть запрещены. Сам скрипт выполняется как `__main__` без правок.
6. **Записываются:**
   - среда: версии Node.js и Python, ОС, время UTC;
   - код выхода и время;
   - stdout и stderr полностью.
7. **Вывод** упаковывается в архив и снабжается sha256. Архив передаётся тебе и Интегратору без обработки.

**Среда сейчас:** Node.js v22.22.0, Python 3.13.16, Linux x86_64.

**Изоляция проверена на пробных скриптах.** Чтение файла ядра по абсолютному пути и запуск дочернего процесса отвергаются: в Node — `ERR_ACCESS_DENIED`, в Python — `PermissionError`.

## 2. Что нужно от скриптов, чтобы их не править

- **Один архив (`.zip`)** и одна строка запуска: язык, входной файл, аргументы. Ты называешь их при сдаче.
- **Только встроенные модули Node.js или стандартная библиотека Python.** Внешних пакетов, сети и запуска процессов нет.
- **Чтение** — только своих файлов, относительно своей папки.
- **Вывод** — в stdout / stderr или в файлы в папке из переменной окружения `KT1_OUT` (Node: `process.env.KT1_OUT`; Python: `os.environ['KT1_OUT']`). Писать в другие места нельзя.
- **Д-3 — путь к ядру только через `KT1_DIR`:**
  - `KT1_DIR` — папка, где лежит `kt1.js`;
  - подключение: `require(path.join(process.env.KT1_DIR, 'kt1'))`.
  - Причина: `require('./kt1')` из интерфейса § 7 работает, только если вызывающий файл лежит в папке ядра, а набор кладётся в свою папку.
  - Зашитых путей быть не должно.
- **А-5 — ядро не упоминается вовсе.** При запуске оно и физически недоступно (п. 1.5).

## 2а. Формат сдачи текстом (для упаковки)

Каждый файл — заголовок и сразу за ним блок кода:

    ### FILE: a5/check1_root.js
    ```js
    …содержимое файла…
    ```

- **Путь** — относительный, без `..` и ведущего `/`.
- **Содержимое блока пишется в файл дословно** и с переводом строки в конце. Если внутри файла встречаются тройные обратные кавычки, ограждай блок четырьмя.
- **Сборка** — `pack_from_text.py`. Порядок файлов — по пути, время фиксированное, без сжатия. Печатается опись: sha256 каждого файла и архива, плюс sha256 исходного текста.
- **Автор сверяет** опись и архив с твоим опубликованным текстом и фиксирует сумму от своего имени. Любой участник может собрать архив тем же правилом и получить ту же сумму.
- **Раздельно:** А-5 и Д-3 — два отдельных текста и два архива.
