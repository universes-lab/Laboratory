## 4. Правка 3 — основание `EXACT` для А-2(ii)/(iii)

**Было:** «κ_r = 1, кольцо по тождеству (ρ = 0)».

**Неверно:** в (ii) и (iii) ρ — не 0; ρ — корень уравнения касания (`fix.free: "rho"`, § 4.2 интерфейса). Кольцо навеса — окружность по тождеству, но по другому правилу.

**Стало:**

| Карточка | Основание полноты |
|---|---|
| **А-2(i)** | κ_r = 1, ρ = 0; кольцо навеса — окружность по тождеству: **П-3** (δ = 0, u ⊥ T при ρ = 0). |
| **А-2(ii)** | κ_r = 1; кольцо навеса — окружность по тождеству: **П-5** (δ = 0, ψ = 0°, T хозяина ⊥ e_z); ρ — корень уравнения касания, не 0. |
| **А-2(iii)** | κ_r = 1; кольцо навеса — окружность по тождеству: **П-5** (δ = 0, ψ = 180°, T хозяина ⊥ e_z); ρ — корень уравнения касания, не 0. |

**Что не меняется:** вывод `EXACT` для κ_r = 1 (аналитика точна); вердикт `PASSED` по геометрии.

**П-5, интерфейс § 3:** «T_навеса = T_хозяина (тождество) — δ = 0 точно и e ⊥ T_хозяина установлено: ρ = 0 или ψ ∈ {0°, 180°} точно, при T_хозяина ⊥ e_z хозяина».

Для (ii): ψ = 0°, но ρ — корень. Значит, применяется правило «ψ ∈ {0°, 180°} точно»; ρ не требуется равным 0. Для (iii) — то же с ψ = 180°.
