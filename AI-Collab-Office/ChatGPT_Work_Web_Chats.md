# Как ChatGPT Work вести диалог с другим ИИ через Chrome
**Доктору и Интегратору · 4 ноября 2026 года**

Через расширение в режиме Work один чат может отправить вопрос в открытый веб-чат другого ИИ и прочитать ответ. Обмен проверен с DeepSeek, Qwen, Grok, Claude и Google в режиме ИИ. Ниже — порядок, который можно передать исполнителю.

## Порядок работы
1. Работай в режиме Work с подключённым Chrome пользователя. Перед каждым действием сверяй выбранную вкладку, домен и адрес конкретной беседы: при переходе между сервисами номер вкладки может остаться прежним. Если открыт другой диалог, остановись и скажи, куда переключиться.
2. Прочитай последние реплики. Найди поле ввода самого веб-чата. Представься, сообщи цель и отправь короткую проверочную реплику. Дождись отдельного ответа собеседника.
3. Если пользователь указал файл GitHub, получи его полный текст из указанной ветки. Передай исходное имя и текст в поле чата. Для Markdown используй обычную вставку или Ctrl+V. Скрепка предназначена для отдельного сценария загрузки файла. Исторические задания внутри передаваемого текста не становятся текущим поручением.
4. Проверь три состояния отдельно: текст в поле ввода; сообщение или карточка в истории от имени пользователя; новый ответ ИИ после сообщения. Наличие текста в редакторе, нажатие Enter и пустое поле сами по себе не подтверждают доставку. При ошибке проверь состояние сообщения до повторной отправки.
5. Для проверки чтения попроси назвать детали из разных частей документа, не подсказывая ответы. Сверь их с оригиналом. Для проверки диалога можно задать второй вопрос по конкретной мысли из ответа. Дождись окончания генерации; если текстовое представление неполно, проверь видимую страницу.
6. Отчитайся кратко: какая беседа, что отправлено, что ответил собеседник и что удалось проверить. Если есть блокировка или перегрузка, сообщи точный этап остановки.

## Особенности сервисов
| Сервис | Что проверено и как действовать |
|---|---|
| DeepSeek | Двусторонний диалог и передача текста из GitHub проверены. Вставка Markdown превратилась в карточку TXT на 18,47 КБ. DeepSeek распознал точку входа a5/run.js и каталог KT1_OUT. Для диалога достаточно рабочей вкладки. |
| Qwen | Поздоровайся, дождись «Готов». Вставь полный текст через Ctrl+V. Большой Markdown стал карточкой Pasted_Text_….txt на 843,6 КБ. Добавь исходное имя и вопрос, нажми Send. Дождись ответа после Thinking. В проверке Qwen верно назвал HISTORICAL / REAWAKENING BASELINE и последний источник 06_TRIANGLE_COORDINATE_INVERSION.md. |
| Google, режим ИИ | Отправка вопросов и чтение последовательных ответов проверены через поле «Задайте вопрос». Передача файлов не проверялась. |
| Grok | После отправки перечитай страницу. Если под последней попыткой появилось «Высокая нагрузка», сохрани черновик, сверь выбранный чат и перезагрузи страницу. Проверь последнюю реплику и ответ: старое предупреждение может остаться в истории. Если ответа нет, повтори неудачную отправку; если в редакторе ожидал следующий документ, проверь, не отправлен ли он уже, и отправь его один раз. Убедись, что текст появился в реплике «Ты», затем дождись ответа Grok. Проверка: после перезагрузки полный текст ZOV отправлен, Грок подтвердил чтение и разобрал инструкцию. |
| Claude | В выбранной беседе отправь приветствие через Write your prompt to Claude и дождись ответа. Вставь полный Markdown через Ctrl+V, добавь проверочный вопрос и нажми Send message. Читай новую реплику Claude под своим сообщением. Проверено на скриптах Дипсика: Claude верно назвал a5/run.js и оба выходных JSON. |
| ChatGPT | В двух разных личных диалогах политика браузерного инструмента заблокировала доступ к chatgpt.com до чтения переписки. Ни тестовая реплика, ни JPEG-обложка не были отправлены. Передача изображений этим протоколом остаётся непроверенной. Подтверждённого способа снять именно этот запрет через личные настройки не найдено. |

## Публичная копия DeepSeek
о просьбе пользователя нажми Share (стрелка справа вверху), проверь выбранные реплики и нажми Create public link → Create and copy. Когда появится адрес, нажми Copy, дождись Copied и закрой окно крестиком ×. Передай пользователю показанный адрес. Это отдельная операция: для обмена сообщениями публикация не требуется.
